### 5.2 详细分析

#### 5.2.1 Go 服务密钥管理

三个 Go 服务的 `auth.go` 均定义 `mustGetenv` 函数：

```go
func mustGetenv(key string) string {
    v := os.Getenv(key)
    if v == "" {
        log.Fatalf("FATAL: environment variable %s is required", key)
    }
    return v
}
```

- `JWT_SIGNING_KEY` 通过 `mustGetenv` 读取，缺失则 fail-fast 退出
- 无任何硬编码弱默认值
- 强制使用 HMAC 算法，避免 `alg=none` 绕过
- 校验 `iss` claim 与过期时间

#### 5.2.2 SQL 注入防护

`JdbcVirtualAdapter.java`：
- 第 128 行：`PreparedStatement stmt = conn.prepareStatement(sql.toString())`
- 第 238-242 行：`bindParameters` 方法通过 `stmt.setObject(i + 1, params.get(i))` 绑定参数
- 第 216-229 行：`validateSourceObject` 白名单校验表名（仅允许 `[a-zA-Z_][a-zA-Z0-9_]*`）
- 谓词通过 `PredicateParser` 解析为结构化条件，值通过参数绑定传递

#### 5.2.3 连接池

`DataSourceManager.java`：
- 使用 `com.zaxxer.hikari.HikariConfig` + `HikariDataSource`
- 配置：最大池大小 10、最小空闲 2、连接超时 30s、空闲超时 10min、最大生命周期 30min
- 按连接 URL 缓存复用连接池

#### 5.2.4 Milvus 真实集成

`vector-engine/Dockerfile` 第 24 行：
```dockerfile
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -tags milvus_enabled -trimpath -ldflags="-s -w" -o /out/vector-engine .
```

启用 `milvus_enabled` build tag，链接真实 Milvus Go SDK，而非内存 Mock 实现。

### 5.3 评级

**A**（从 C- 提升至 A，达标）

- 无硬编码密钥（3 个 Go 服务全部 mustGetenv）
- PreparedStatement 参数化查询（防 SQL 注入）
