# 商业化运营闭环

> 版本：2026-09-11 ｜ 状态：**方案设计** ｜ 关联文档：[BILLING-DECISION.md](../BILLING-DECISION.md)、[产品原型设计 v0.4](../../design/多平台多租户大数据平台_产品原型设计_v0.4.md)、[组件成熟度矩阵](../component-maturity.md)

## 一、文档目的

本文档补全数据引擎大数据平台（DataEngineBDP）商业化运营闭环的产品策略文档，覆盖从定价、合同、计费到交付运维的全链路运营流程。现有文档（[BILLING-DECISION.md](../BILLING-DECISION.md)）已明确计费技术路线决断（推荐方案 A：轻量内建），本文档在此基础上补全运营层面的策略与流程设计。

## 二、定价策略

### 2.1 定价模式总览

平台支持三种定价模式，按交付场景差异化选用：

| 定价模式 | 适用场景 | 计费粒度 | 适用客户 | 现状 |
| --- | --- | --- | --- | --- |
| **套餐定价** | 私有化交付（信创/本地/私有云） | 年费/项目费 | 政企客户 | ✅ 主推模式 |
| **按量计费** | 公有云 SaaS | API 调用次数 / 存储量 / 计算资源 | SaaS 租户 | ⚠️ 出账已实现，结算/支付/分账待实施 |
| **混合计费** | 大客户 SaaS + 私有化混合 | 套餐基础费 + 超量按量 | 大型企业 | 📋 规划中 |

### 2.2 套餐定价（私有化交付主推）

| 套餐层级 | 包含能力 | 年化 TCO 区间（含实施+节点+信创适配） | 适用规模 |
| --- | --- | --- | --- |
| **基础版** | 湖仓一体 + 数据治理 + SQL 网关 + 多租户 | 50-100 万/年 | 单租户，数据量 < 10TB |
| **标准版** | 基礀版 + 行业模板 | 100-300 万/年 | 多租户，数据量 < 100TB |
| **企业版** | 标准版 + AI 能力（LLMOps + RAG） + 多集群联邦 + 信创适配 + FinOps + 数据资产流通 | 300-800 万/年 | 多集群，数据量 > 100TB |

> 定价口径对齐 [产品原型设计 v0.4](../../design/多平台多租户大数据平台_产品原型设计_v0.4.md) §11.5.4（基础版许可 20 万 + 年服务 4 万、标准版许可 50 万 + 年服务 10 万、企业版许可 150 万 + 年服务 30 万）；上表区间为含实施+节点+信创适配的年化 TCO，纯许可+服务费见 §11.5.4。包含能力对齐 §11.5.1 套餐矩阵。

**套餐包含内容**：
- 平台软件许可（永久使用权或订阅权）
- SKE 交付底座部署服务
- 一年技术支持（远程）
- 行业模板套装（当前 3 套基础模板已实现，目标 9 套，已完成 3/9；按版本差异化规划（对齐 §11.5.7）：基础版不可用（0 套）/ 标准版 3 套 / 企业版 9 套）

**超量加费**：超出套餐包含的数据量/API 调用数，按阶梯加费（详见 §2.4）。

### 2.3 按量计费（公有云 SaaS）

| 计费维度 | 计量单位 | 单价（参考） | 计量来源 |
| --- | --- | --- | --- |
| API 调用 | 次 | 0.01-0.05 元/次 | `open-api-catalog` MeteringService（AK/SK 计量，✅ 已实现） |
| 存储 | GB/月 | 0.5-2 元/GB/月 | Iceberg/MinIO 存储配额统计 |
| 计算资源 | 核·时 | 0.5-2 元/核·时 | Spark/Flink 作业资源用量 |
| 数据资产交易 | 笔 | 交易额 × 5-15% | `asset-exchange` settlement_service（✅ 已实现） |

**现状**：计量数据采集层已就绪（[BILLING-DECISION.md](../BILLING-DECISION.md) §一），出账已实现，结算/支付/分账待实施。

### 2.4 混合计费

大客户可采用"套餐基础费 + 超量按量"模式：
- 基础套餐费：按年预付，锁定最低消费
- 超量部分：按 §2.3 按量计费，阶梯优惠

| 超量区间 | 阶梯优惠 |
| --- | --- |
| 0-110% 套餐额度 | 不加费 |
| 110-150% | 按标准单价 |
| 150-200% | 标准单价 × 0.9 |
| > 200% | 标准单价 × 0.8 |

## 三、合同流程

### 3.1 合同生命周期

```
签订 → 生效 → 履约期（交付+运维） → 续约/终止
```

### 3.2 合同签订流程

| 步骤 | 责任方 | 产出 | 周期 |
| --- | --- | --- | --- |
| 1. 需求确认 | 销售 + 客户 | 需求清单 + 套餐选型 | 1-2 周 |
| 2. 方案设计 | 售前架构师 | 部署方案 + 资源清单 | 1-2 周 |
| 3. 商务报价 | 销售 + 商务 | 报价单（含套餐/超量/服务费） | 3-5 天 |
| 4. 合同起草 | 法务 | 合同文本（含 SLA 条款） | 1 周 |
| 5. 合同审批 | 法务 + 财务 + 总经理 | 审批通过 | 1-2 周 |
| 6. 签署生效 | 双方签署 | 生效合同 + 项目立项 | 1-3 天 |

### 3.3 合同续约

| 触发条件 | 流程 |
| --- | --- |
| 合同到期前 90 天 | 系统自动提醒销售 |
| 合同到期前 60 天 | 客户续约意向确认 |
| 合同到期前 30 天 | 续约合同签署 |
| 合同到期 | 未续约则进入终止流程 |

**续约调价机制**：
- 连续合作 2 年以上：续约优惠 5%
- 连续合作 3 年以上：续约优惠 10%
- 版本升级附加费：如从基础版升级到标准版，按差价 × 剩余周期比例收取

### 3.4 合同终止

| 终止类型 | 流程 | 数据处理 |
| --- | --- | --- |
| **正常终止**（到期不续） | 提前 30 天书面通知 → 数据迁移窗口 → 平台停服 → 数据销毁确认 | 客户数据导出（30 天窗口）后销毁 |
| **提前终止**（客户违约） | 违约金结算 → 数据迁移 → 停服 | 按合同约定违约金，数据导出后销毁 |
| **提前终止**（平台违约） | SLA 赔付 → 数据迁移 → 停服 | 按 SLA 条款赔付，数据导出后销毁 |

## 四、计费规则

### 4.1 计费维度

| 维度 | 数据来源 | 采集频率 | 存储位置 |
| --- | --- | --- | --- |
| API 调用次数 | `open-api-catalog` MeteringService | 实时 | SQLite（`data/openapi_catalog.db`） |
| 资产交易额 | `asset-exchange` settlement_service | 实时 | SQLite（`data/asset_exchange.db`） |
| 存储用量 | MinIO/Iceberg 配额统计 | 每日 | FinOps cost-model |
| 计算资源 | Spark/Flink 作业计量 | 每作业 | FinOps cost-model |
| 租户/工作空间维度 | encaps-layer 租户上下文 | 实时 | encaps-layer DB |

### 4.2 账单生成

**账单周期**：

| 计费模式 | 账单周期 | 生成时间 |
| --- | --- | --- |
| 套餐定价 | 年度 | 合同生效日 + 365 天 |
| 按量计费 | 月度 | 每月 1 日生成上月账单 |
| 混合计费 | 月度 + 年度 | 月度出超量账单，年度出套餐账单 |

**账单生成流程**（对应 [BILLING-DECISION.md](../BILLING-DECISION.md) 方案 A）：

```
计量数据汇总 → 账单实体生成（草稿）→ 账单审核（管理员确认）→ 账单发出 → 客户支付 → 账单关闭
```

**账单状态机**：

| 状态 | 含义 | 后续动作 |
| --- | --- | --- |
| `DRAFT` | 草稿（系统生成） | 管理员审核 |
| `CONFIRMED` | 已确认（管理员审核通过） | 发送客户 |
| `SENT` | 已发送 | 等待客户支付 |
| `PAID` | 已支付 | 账单关闭 |
| `OVERDUE` | 逾期（超付款期限） | 催收流程 |
| `CLOSED` | 已关闭 | 归档 |

### 4.3 付款周期与方式

| 交付场景 | 付款方式 | 付款周期 | 账期 |
| --- | --- | --- | --- |
| 私有化交付 | 对公银行转账 | 合同签订后 30 天内预付 | 预付 100% |
| SaaS 按量 | 在线支付（微信/支付宝企业）| 月结 | 后付，账单发出后 30 天 |
| 混合 | 预付 + 后付 | 套餐预付 + 超量月结 | 套餐预付，超量后付 |

**现状**：方案 A（轻量内建）采用线下对公转账 + 管理员手工核销，不做在线支付网关。方案 B（完整商业化）需对接支付网关（详见 [BILLING-DECISION.md](../BILLING-DECISION.md) §二）。

## 五、交付流程

### 5.1 交付生命周期

```
开通 → 配置 → 验收 → 运维 →（续约/终止）
```

### 5.2 平台开通

| 步骤 | 责任方 | 产出 | 周期 |
| --- | --- | --- | --- |
| 1. 环境准备 | 实施 + 客户 | 基础设施就绪（VM/裸金属/K8s 集群） | 1-2 周 |
| 2. SKE 部署 | 实施工程师 | SKE 交付底座就绪 | 1-3 天 |
| 3. 平台引导 | 实施工程师 | `bootstrap.sh` 执行成功 | 1 天 |
| 4. Helm Chart 部署 | 实施工程师 | 88 个 Chart 按需部署 | 2-5 天 |
| 5. 租户初始化 | 实施工程师 | 初始租户 + 管理员账号 | 1 天 |
| 6. 行业模板安装 | 实施工程师 | 按套餐安装行业模板 | 1-2 天 |

**四环境交付**（零改动交付，详见 [README](../../README.md)）：

| 环境 | Profile | 交付方式 |
| --- | --- | --- |
| 信创 | `xinchang` | `infra-provider-xinchang` Driver |
| 本地数据中心 | `local` | `infra-orchestrator` + kubeadm |
| 公有云 | `cloud` | `infra-provider-cloud` Driver |
| 私有云 | `private` | `infra-provider-private` Driver |

### 5.3 平台配置

| 配置项 | 配置方式 | 参考 |
| --- | --- | --- |
| 数据源连接 | 控制台 → 数据源管理 | [用户手册](../user-guide/user-manual.md) |
| 计算引擎参数 | Helm values + Profile | [部署指南](../deployment-guide.md) |
| 租户配额 | 控制台 → 工作空间管理 | encaps-layer API |
| 安全策略 | Keycloak Realm + APISIX 插件链 | [JWT 指南](../JWT-KEY-ROTATION-GUIDE.md) |
| 监控告警 | Grafana + Alertmanager | [运维手册](../user-guide/ops-manual.md) |

### 5.4 验收标准

| 验收项 | 验收标准 | 验证方式 |
| --- | --- | --- |
| 平台可用性 | 所有核心服务健康检查通过 | `kubectl get pods` 全 Running |
| 数据链路 | 端到端 PoC 全通过 | `bash scripts/poc/run-poc.sh` |
| SQL 网关 | 跨源查询成功 | PoC verify-sql-gateway.sh |
| 多租户隔离 | 租户间数据/网络隔离验证 | 集成测试 test_tenant_isolation |
| 行业模板 | 模板部署成功且可访问 | helm install + 服务访问验证 |
| 监控可观测 | Grafana 看板可访问 | 浏览器访问 Grafana |
| 安全合规 | 等保三级/密评通过 | 安全审计报告 |

### 5.5 运维服务

| 服务等级 | 响应时间 | 处理时间 | 适用套餐 |
| --- | --- | --- | --- |
| **P0 紧急**（平台不可用） | 30 分钟 | 4 小时 | 全部 |
| **P1 严重**（核心功能不可用） | 1 小时 | 8 小时 | 全部 |
| **P2 一般**（功能异常） | 4 小时 | 2 工作日 | 标准版/企业版 |
| **P3 轻询**（使用咨询） | 1 工作日 | 5 工作日 | 标准版/企业版 |

**运维内容**：
- 日常监控：Grafana 看板 + Alertmanager 告警
- 定期巡检：每周健康检查报告
- 版本升级：按合同约定提供升级服务（详见 [升级指南](../user-guide/upgrade-guide.md)）
- 安全加固：漏洞修复 + 安全补丁
- 容量规划：基于 FinOps 成本模型提供扩容建议

## 六、SLA 条款

| SLA 指标 | 目标值 | 赔付方式 |
| --- | --- | --- |
| 平台可用性 | ≥ 99.9%（月度） | 低于目标按月费 × (1 - 可用率) 赔付 |
| SQL 查询延迟（P95） | < 5 秒（跨源）/ < 1 秒（单源） | 超出按查询量 × 0.01 元赔付 |
| 数据写入延迟 | < 10 秒（流式）/ 批量按 SLA 约定 | 超出按数据量 × 0.005 元赔付 |
| 故障恢复时间（RTO） | < 4 小时 | 超出按月费 × 10% 赔付 |
| 数据恢复时间（RPO） | < 1 小时 | 超出按数据量 × 0.01 元赔付 |
