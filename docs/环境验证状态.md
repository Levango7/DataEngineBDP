## staging 环境配置说明

### 已有配置（本地 + 本地数据中心）

- `design/deploy/values/env/dev/` — 开发环境（最小资源 · H2/SQLite · 无 PVC）
- `design/deploy/values/env/staging/` — 预发环境（中等资源 · PostgreSQL · PDB）
- `design/deploy/values/env/prod/` — 生产环境（充足资源 · PVC · HPA · TLS）

### 新增配置（信创 + 公有云 + 私有云）

- `design/deploy/values/env/staging-xinchuang/` — 信创 staging 配置骨架
  - 国密 SM2/SM3/SM4 · openEuler 镜像变体 · TLCP 传输 · 国产对象存储
- `design/deploy/values/env/staging-publiccloud/` — 公有云 staging 配置骨架
  - 标准 AES · Ubuntu 镜像 · TLS · S3 对象存储（客户提供密钥）
- `design/deploy/values/env/staging-privatecloud/` — 私有云 staging 配置骨架
  - AES+SM4 混合 · RockyLinux 镜像 · 厂商对象存储/MinIO

> **注意**：以上三套配置为 staging 基础骨架，实际部署前须替换占位密钥为
> KMS/Secret 注入的真实凭据，并确认目标环境硬件/VM 就绪。
