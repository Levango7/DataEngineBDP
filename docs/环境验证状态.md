### 验证检查清单与通过标准

| 检查项 | 验证方法 | 通过标准 | 脚本覆盖 |
|--------|----------|----------|----------|
| K8s 集群连通性 | `kubectl get nodes` | 所有节点 Ready=True | ✅ `check_k8s_cluster` |
| 核心服务 Pod 就绪 | `kubectl get deployment` | readyReplicas == replicas | ✅ `check_core_services` |
| 数据组件 Pod 就绪 | `kubectl get statefulset/deployment` | readyReplicas == replicas | ✅ `check_data_components` |
| 数据库连通性 | TCP 端口探测 / `pg_isready` | 端口可达且 DB 响应 | ✅ `check_database_connectivity` |
| API 网关健康端点 | `curl /actuator/health` | HTTP 200 | ✅ `check_api_gateway` |
| API 网关根路径可达 | `curl /` | HTTP 200/302/401 | ✅ `check_api_gateway` |
| 前端页面可访问 | `curl -L <frontend_url>` | HTTP 200 | ✅ `check_frontend` |

### 冒烟测试脚本使用

```bash
# 测试单个环境
./scripts/env-deploy-smoke-test.sh dev
./scripts/env-deploy-smoke-test.sh staging
./scripts/env-deploy-smoke-test.sh pre-prod
./scripts/env-deploy-smoke-test.sh prod

# 遍历所有环境
./scripts/env-deploy-smoke-test.sh --all

# 详细输出
./scripts/env-deploy-smoke-test.sh dev --verbose
```

**退出码**：0 = 全部通过，1 = 存在失败，2 = 参数/依赖错误
