### 1.3 测评目的

依据《中华人民共和国网络安全法》第二十一条、GB/T 22239-2019 等保第三级安全要求，对数擎大数据平台 V2.0 进行网络安全等级保护三级测评，验证平台在物理环境、通信网络、区域边界、计算环境、管理中心五大层面的安全防护能力是否满足等保三级要求，识别安全风险与不符合项，提出整改建议，为系统稳定运行和数据安全提供保障。

### 1.4 测评范围

本次测评覆盖数擎大数据平台 V2.0 全部生产环境，包括：

- **物理环境**：北京亦庄数据中心 A 栋 3 层主机房、4 层网络机房（T3+ 标准机房）。
- **通信网络**：跨可用区 VPC、租户专网、K8s Pod 网络（Calico BGP）、API 网关到内部服务链路。
- **区域边界**：互联网边界（APISIX 网关）、办公网边界（堡垒机）、租户间边界（NetworkPolicy）、DMZ 与内网边界。
- **计算环境**：K8s 控制面与数据面节点、Spark/Flink/Trino/Doris 计算引擎、Iceberg/MinIO 存储集群、Keycloak 身份认证服务、PostgreSQL/Redis 等数据库。
- **管理中心**：SKE 运营后台、SecurityFacade 统一安全门面、CryptoSpiFactory 密码服务抽象、日志审计中心、监控告警中心（Prometheus + Grafana + Loki）。

### 1.5 测评方法

- **访谈**：与系统管理员、安全管理员、安全审计员、应用开发负责人进行结构化访谈。
- **文档审查**：审查安全管理制度、操作规程、网络拓扑图、系统设计文档、配置基线、日志审计记录。
- **配置核查**：使用核查脚本与人工方式核查操作系统、数据库、中间件、网络设备的安全配置。
- **技术测试**：使用漏洞扫描（Nessus、OpenVAS）、配置核查（CIS-CAT、自研脚本）、渗透测试（自研工具 + Burp Suite）、密码验证（商用密码检测工具）等手段开展技术测试。
- **综合评估**：依据 GB/T 22239-2019 单项判定规则，给出符合 / 部分符合 / 不符合的测评结论。

## 第8章 总体测评结论

数擎大数据平台 V2.0 在物理环境、通信网络、区域边界、计算环境、管理中心五大层面已基本满足 GB/T 22239-2019 等保三级安全要求。本次测评共测评 34 项，符合 30 项，部分符合 4 项，不符合 0 项，总体符合率 88.2%。
