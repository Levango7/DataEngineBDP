# 数据引擎大数据平台 V2.0.0 勘误公告（Erratum）

> 编号：ERRATUM-V2.0.0-01　|　发布日期：2026-08-26　|　效力范围：`releases/v2.0.0/` 发布包全部物料
>
> 本公告为正式勘误文件，用于更正 V2.0.0 发布物料中与发布检查清单相矛盾的表述。

---

## 一、勘误决定：GA 定级修订为 RC

**V2.0.0 的版本定级由 General Availability（GA，正式可用版本）修订为 Release Candidate（RC，候选版本）。**

依据：同目录 `ga-checklist.md`（GA 发布检查清单）自报通过率为 **74.1%（40/54）**，其中 **四环境零改动检查 0/6 通过**、全部标注"需实际环境验证"；且该清单自述"所有检查项必须通过方可正式发布"，其发布结论栏与签字栏均未完成。在此状态下，`release-notes.md` 以"General Availability（正式可用版本）"口径对外发布，属于同一发布包内的直接矛盾，现予以更正。

## 三、V2.0.0 真实定位

- **交付性质**：以骨架与文档交付为主体（53 个开发任务的骨架与文档交付），配套设计文档、用户文档、合规文档与 Helm Chart 骨架体系。
- **核心链路可用**：7 条端到端链路已落地（数据集成 / 批计算 / 流计算 / 交互查询 / 治理闭环 / BI 可视化 / 多租户隔离），SQL 网关接真实引擎后端、治理闭环、多租户隔离、NL2SQL→联邦查询等链路经端到端验证。
- **AI 层为演示模式**：vector-engine、llm-gateway、llmops、ml-platform、knowledge-engine、model-finetuning 等 AI 相关组件默认运行于 Mock / 演示模式，真实后端（Milvus、LLM Provider、MLflow、GPU 训练框架等）需显式配置或专用构建方可启用。逐组件状态详见 [组件成熟度矩阵](../../docs/component-maturity.md)。
- **安全合规**：等保三级测评、密评及整改闭环材料齐备（`docs/compliance/`），该部分验收结论不受本勘误影响。

## 四、历史文件处理原则

本勘误遵循**不删改历史文件原文**原则：`release-notes.md` 与 `ga-checklist.md` 原文保留不动，其与事实不符之处以本公告为准。引用 V2.0.0 物料时请结合本公告阅读。

## 五、后续行动

1. 对外口径统一按"V2.0.0 RC"表述；GA 定级须在 ga-checklist 全部 54 项通过并完成签字后方可恢复。
2. 补齐四环境实际部署验证、升级 / 回滚验证与性能基线实测（对应 ga-checklist 第 9.4.3 节 P2 项）。
3. 持续推进各组件由演示模式转向真实后端（进度见组件成熟度矩阵"关键缺口"列）。
