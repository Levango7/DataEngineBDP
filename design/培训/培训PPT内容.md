### P4 平台总体架构 · 五层 + 一横切

- **标题**：平台总体架构：五层 + 一横切

  - L5 产品层：统一控制台 / 运营后台 / 行业模板 / 开放 API / FinOps

  - L0 基础设施层：K8s / Helm / ArgoCD / 可观测基座

### P11 核心概念：租户

- **标题**：核心概念：租户（Tenant）
- **内容要点**：
  - 定义：平台顶层资源边界，对应一个客户组织
  - 资源边界：K8s Namespace + 资源配额 + 网络策略
  - 生命周期：创建 → 配置 → 运行 → 冻结 → 销毁

### P12 核心概念：项目与工作空间

- **标题**：核心概念：项目（Project）与工作空间（Workspace）
- **内容要点**：
  - 项目：租户内业务边界，隔离权限与计费
  - 工作空间：项目内引擎/数据隔离单元
  - 一个租户可含多个项目，一个项目可含多个工作空间
  - 工作空间绑定引擎队列与数据湖路径

- **内容要点**：
  - 引擎：Spark/Flink/Trino/Doris，按需启用
  - 作业：在引擎上运行的具体任务（批/流/SQL/Notebook）
  - 作业状态：草稿/已提交/运行中/成功/失败/已停止

### P14 核心概念：数据集与数据资产

  - 数据资产：经治理登记的可发现数据，含元数据/血缘/质量评分
  - 数据资产目录：全租户可检索，支持订阅与申请
