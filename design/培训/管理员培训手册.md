## 第1章 平台登录与导航

### 1.1 平台访问地址

平台控制台通过 HTTPS 访问，不同环境域名不同：

| 环境 | 域名 | 说明 |
| --- | --- | --- |
| 生产 | `https://console.prod.dataengine.example.com` | 生产环境，仅授权 IP 可访问 |
| 预发 | `https://console.staging.dataengine.example.com` | 预发布环境，用于发布前验证 |
| 测试 | `https://console.test.dataengine.example.com` | 测试环境，培训使用 |
| 本地开发 | `https://console.dev.dataengine.local` | 本地开发环境 |

> 培训期间使用测试环境，账号由培训讲师发放，每人一套。

### 1.2 登录方式

平台支持四种登录方式，由管理员在租户级配置启用：

1. **账号密码**：默认方式，密码须满足复杂度（≥12 位，含大小写+数字+符号）。
2. **LDAP**：对接企业 LDAP/AD，账号密码由 LDAP 校验。
3. **OAuth2**：对接企业 SSO（如 OAuth2/OIDC），跳转第三方登录。
4. **国密 USB Key**：信创环境强制方式，SM2 证书 + USB Key 双因子。

#### 1.2.1 账号密码登录步骤

1. 浏览器访问控制台域名。
2. 输入账号（邮箱或用户名）与密码。
3. 首次登录强制修改密码并绑定 MFA（扫码或 TOTP）。
4. 后续登录需输入 MFA 验证码。
5. 登录成功跳转控制台首页。

#### 1.2.2 国密 USB Key 登录步骤

1. 插入 USB Key，安装驱动（首次）。
2. 访问控制台，选择"国密 Key 登录"。
3. 输入 USB Key PIN 码。
4. 浏览器调用 USB Key 完成 SM2 签名挑战。
5. 签名通过则登录成功。

登录后控制台分为四大区域：

#### 1.3.1 顶部栏

- **全局搜索**：支持搜索租户/用户/作业/数据集/仪表盘，快捷键 `Ctrl+K`。
- **租户切换**：平台管理员可见所有租户，租户管理员仅可见本租户。
- **项目切换**：在选中租户下切换项目。
- **用户菜单**：个人信息 / 修改密码 / MFA 管理 / 切换主题 / 退出。
- **帮助**：在线文档 / 快捷键 / 联系支持 / 关于。

#### 1.3.2 左侧导航菜单

| 一级菜单 | 子菜单 | 角色 |
| --- | --- | --- |
| 概览 | 工作台 / 通知 / 待办 | 全角色 |
| 数据 | 数据集成 / 数据源 / 数据湖 | 工程师/分析师 |
| 开发 | 作业开发 / SQL 网关 / 调度 | 工程师 |

> 管理员菜单仅"平台管理员"和"租户管理员"可见，普通用户不可见。

### 1.4 首次登录设置

首次登录须完成以下设置，否则无法进入主功能：

1. **修改初始密码**：初始密码由管理员发放，须改为本人密码。
2. **绑定 MFA**：扫码绑定钉钉/企业微信，或扫码绑定 TOTP（Google Authenticator）。
3. **签署保密协议**：首次进入须电子签署数据保密协议。
4. **完善个人信息**：姓名/部门/职位/联系方式（便于审计与通知）。

## 第2章 租户管理

### 2.1 租户概念

租户（Tenant）是平台顶层资源边界，对应一个客户组织。每个租户拥有独立的：

- K8s 命名空间集合（`tenant-<id>-*`）
- 资源配额（CPU/内存/存储/作业数）
- 网络策略（隔离入向/出向流量）
- 数据湖路径前缀（`/tenant-<id>/`）
- 用户与角色集合
- 计费账单

### 2.2 租户生命周期

租户生命周期包含 5 个状态：

```text
创建中 → 运行中 → 已冻结 → 已销毁 → 回收站
   │        │        │        │
   └────────┴────────┴────────┘
       （异常可转"创建失败"）
```

| 状态 | 含义 | 允许操作 |
| --- | --- | --- |
| 创建中 | 异步创建命名空间/配额/默认角色 | 等待 / 取消 |
| 运行中 | 正常可用 | 配置 / 冻结 / 销毁 |
| 已冻结 | 暂停作业，保留数据 | 解冻 / 销毁 |
| 已销毁 | 软删除，进入回收站 | 恢复 / 彻底删除 |
| 回收站 | 30 天保留期 | 恢复 / 彻底删除 |

### 2.3 创建租户

#### 2.3.1 入口

`管理 → 租户管理 → 新建租户`

#### 2.3.2 表单字段

| 字段 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| 租户名称 | 是 | 显示名，可中文 | `某零售集团` |
| 租户编码 | 是 | 全局唯一，小写字母+数字 | `retail-corp` |
| 套餐 | 是 | 决定默认配额 | `标准` / `企业` / `定制` |
| 管理员账号 | 是 | 租户管理员登录账号 | `admin@retail-corp` |
| 管理员邮箱 | 是 | 接收初始密码与通知 | `admin@retail-corp.com` |
| 租户描述 | 否 | 备注信息 | `某零售集团生产租户` |
| 到期时间 | 否 | 不填则长期有效 | `2027-08-18` |
| 标签 | 否 | 用于筛选与计费 | `行业:零售, 等级:VIP` |

#### 2.3.3 操作步骤

1. 进入租户管理列表页，点击"新建租户"。
2. 填写表单字段，选择套餐。
3. 点击"提交"，弹出确认对话框。
4. 确认后列表中出现新租户，状态为"创建中"。
5. 等待 1–3 分钟，状态变为"运行中"，租户管理员收到初始密码邮件。
6. 点击租户名称进入详情页，可查看命名空间、配额、默认角色。

#### 2.3.4 命令行等价操作

```bash
# 命令示例：通过平台 CLI 创建租户
debdp tenant create \
  --name "某零售集团" \
  --code "retail-corp" \
  --plan "standard" \
  --admin "admin@retail-corp" \
  --email "admin@retail-corp.com" \
  --expire "2027-08-18"
```

### 2.4 配置租户

进入租户详情页可配置以下内容：

#### 2.4.1 套餐升级

- 路径：`租户详情 → 套餐 → 升级`
- 升级仅可向上（试用 → 标准 → 企业 → 定制），不可降级。
- 升级后配额按新套餐默认值调整，可手动微调。
- 升级即时生效，按比例计算差价账单。

#### 2.4.2 配额调整

- 路径：`租户详情 → 配额`
- 可调整 CPU/内存/存储/作业数/引擎实例数。
- 调整须确认，变更记录入审计日志。
- 详见第 4 章。

#### 2.4.3 到期延期

- 路径：`租户详情 → 到期时间 → 延期`
- 延期须审批（平台管理员审批租户管理员的延期申请）。
- 到期前 30 天系统自动告警提醒续费。

#### 2.4.4 标签管理

- 路径：`租户详情 → 标签`
- 标签用于筛选、计费维度、成本分摊。
- 标签键值须符合 `^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$`。

### 2.5 冻结与解冻租户

#### 2.5.1 冻结

- 适用场景：租户欠费 / 违规 / 客户主动要求暂停。
- 操作：`租户详情 → 操作 → 冻结`，输入冻结原因。
- 效果：
  - 所有运行中作业被停止（保留 Checkpoint）。
  - 控制台只读，禁止新建/编辑/提交操作。
  - 数据保留，不删除。
  - 计费暂停（仅收存储费）。
- 通知：冻结后租户管理员与所有用户收到邮件/钉钉通知。

#### 2.5.2 解冻

- 操作：`租户详情 → 操作 → 解冻`，输入解冻原因。
- 效果：恢复控制台可写，作业可手动重启，计费恢复。
- 解冻后须人工检查关键作业是否需要重启。

### 2.6 销毁租户

#### 2.6.1 销毁流程

1. `租户详情 → 操作 → 销毁`。
2. 弹窗显示销毁影响清单（数据量/作业数/用户数）。
3. 输入租户编码确认（防误操作）。
4. 输入验证码（邮件发送）。
5. 点击"确认销毁"，租户进入"已销毁"状态，转入回收站。

#### 2.6.2 销毁效果

- K8s 命名空间保留 30 天（回收站），30 天后彻底删除。
- 数据湖路径保留 30 天，30 天后彻底删除。
- 元数据库记录软删除，30 天后彻底删除。
- 计费账单保留 7 年（合规要求）。
- 审计日志保留 7 年。

#### 2.6.3 恢复（回收站）

- 路径：`租户管理 → 回收站`
- 30 天内可"恢复"，租户回到"已冻结"状态，须人工解冻。
- 恢复后须校验数据完整性与作业状态。

### 2.7 租户管理 FAQ

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 创建租户长时间"创建中" | K8s 资源不足 / 命名空间冲突 | 查看创建日志，联系运维 |
| 冻结后仍有作业运行 | 异步停止有延迟（< 5 分钟） | 等待或手动停止 |
| 销毁后回收站找不到 | 已过 30 天保留期 | 联系运维从备份恢复 |
| 租户编码重复 | 编码全局唯一 | 改用其他编码 |
| 管理员邮箱收不到密码 | 邮箱被拦截 / 地址错误 | 检查邮箱 / 联系管理员重发 |

## 第3章 用户与权限管理

### 3.1 用户概念

用户（User）是平台操作的执行主体，归属于租户。一个用户只能属于一个租户（跨租户须用不同账号）。用户来源：

- **本地用户**：平台自管账号，密码平台存储（国密 SM4 加密）。
- **LDAP 用户**：从企业 LDAP/AD 同步，密码由 LDAP 校验。
- **OAuth2 用户**：从企业 SSO 联合，账号由 IdP 校验。

### 3.2 系统角色

平台预置 6 个系统角色，覆盖常见场景：

| 角色 | 编码 | 权限范围 | 适用对象 |
| --- | --- | --- | --- |
| 平台管理员 | `platform_admin` | 全平台所有操作 | 平台运营方 |
| 租户管理员 | `tenant_admin` | 本租户所有操作 | 客户租户管理员 |
| 数据工程师 | `data_engineer` | 数据/开发/治理 | 数据开发人员 |
| 数据分析师 | `data_analyst` | BI/SQL/资产目录 | 业务分析人员 |
| 运维工程师 | `ops_engineer` | 运维/监控/告警 | 运维人员 |
| 只读用户 | `readonly` | 全平台只读 | 审计/合规人员 |

> 平台管理员与租户管理员的区别：平台管理员可管理所有租户，租户管理员仅可管理本租户。

### 3.3 创建用户

#### 3.3.1 入口

`管理 → 用户管理 → 新建用户`

#### 3.3.2 表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 账号 | 是 | 登录账号，建议邮箱格式 |
| 姓名 | 是 | 显示名 |
| 邮箱 | 是 | 接收通知与初始密码 |
| 手机 | 否 | 接收短信告警 |
| 初始密码 | 是 | 须满足复杂度，首次登录强制修改 |
| 所属租户 | 是 | 平台管理员可选任意租户，租户管理员固定本租户 |
| 角色 | 是 | 可多选，权限取并集 |
| 所属项目 | 否 | 可多选，决定项目可见性 |
| 标签 | 否 | 用于筛选与审计 |

#### 3.3.3 操作步骤

1. 进入用户管理列表页，点击"新建用户"。
2. 填写表单，选择角色与项目。
3. 点击"提交"，用户创建成功。
4. 用户收到初始密码邮件，首次登录强制改密 + 绑定 MFA。

### 3.4 编辑与启停用户

#### 3.4.1 编辑用户

- 路径：`用户列表 → 用户详情 → 编辑`
- 可修改：姓名/邮箱/手机/角色/项目/标签。
- 不可修改：账号（创建后固定）/ 所属租户。

#### 3.4.2 禁用与启用

- **禁用**：用户立即踢出登录，无法再登录，但保留数据与历史。
- **启用**：恢复登录能力。
- 适用场景：员工离职临时禁用，复职启用。

#### 3.4.3 重置密码

- 路径：`用户详情 → 重置密码`
- 方式：管理员设置新密码 / 系统生成随机密码邮件发送。
- 重置后用户下次登录须改密。

### 3.5 角色与权限矩阵

#### 3.5.1 权限粒度

平台权限分三个粒度：

1. **菜单级**：控制左侧菜单可见性。
2. **操作级**：控制按钮可用性（如"新建""删除""提交"）。
3. **数据级**：控制数据可见范围（行级/列级，基于 ABAC）。

#### 3.5.2 权限矩阵

路径：`管理 → 角色管理 → 角色 → 权限矩阵`

权限矩阵以"角色 × 资源"二维表展示，每格可设：

- **允许**：显式允许。
- **拒绝**：显式拒绝（优先级最高）。
- **继承**：继承父角色或默认策略。

#### 3.5.3 数据级权限

数据级权限基于属性（ABAC）实现，典型规则：

- 行级：仅可见本人 Owner 的数据（`owner = ${current_user}`）。
- 行级：仅可见本部门数据（`dept = ${current_user.dept}`）。
- 列级：脱敏手机号（`mask(phone, 3, 4)`）。

### 3.6 自定义角色

#### 3.6.1 创建自定义角色

1. `角色管理 → 新建角色`。
2. 填写角色名称、编码、描述。
3. 在权限矩阵中勾选允许/拒绝的操作。
4. 配置数据级权限规则（可选）。
5. 保存角色，可在用户管理中分配。

#### 3.6.2 角色继承

- 自定义角色可继承系统角色，自动获得父角色权限。
- 可在继承基础上增加或拒绝特定权限。
- 继承层级最多 3 层，避免过深。

### 3.7 用户与权限管理 FAQ

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 用户登录后看不到菜单 | 角色权限不足 | 检查角色权限矩阵 |
| 用户可登录但无法操作 | 操作级权限拒绝 | 检查操作级权限 |
| 用户看到数据为空 | 数据级权限限制 | 检查 ABAC 规则 |
| LDAP 同步失败 | LDAP 配置错误 / 网络不通 | 检查 LDAP 配置与连通性 |
| 一个用户多角色权限冲突 | 拒绝优先级最高 | 显式拒绝覆盖允许 |

## 第4章 资源配额管理

### 4.1 配额维度

平台资源配额分 5 个维度：

| 维度 | 单位 | 说明 |
| --- | --- | --- |
| CPU | 核（core） | 所有 Pod CPU 请求之和上限 |
| 内存 | Gi | 所有 Pod 内存请求之和上限 |
| 存储 | Gi | 数据湖 + 元数据库 + 日志存储上限 |
| 作业数 | 个 | 同时运行作业数上限 |
| 引擎实例数 | 个 | 各引擎 Controller/Executor 实例数上限 |

### 4.2 配额层级

配额分三级，上级配额是下级配额的上限：

```text
租户级配额
   └─ 项目级配额
        └─ 工作空间级配额
```

- **租户级**：租户总配额，由平台管理员设置。
- **项目级**：项目配额，由租户管理员设置，不超过租户级。
- **工作空间级**：工作空间配额，由项目管理员设置，不超过项目级。

### 4.3 配额查看

#### 4.3.1 入口

`管理 → 资源配额`

#### 4.3.2 总览页

总览页展示所有租户配额使用情况：

- 租户名称 / 套餐 / CPU 使用率 / 内存使用率 / 存储使用率 / 作业数使用率。
- 使用率颜色：绿（< 70%）/ 黄（70–90%）/ 红（> 90%）。
- 点击租户进入详情，可查看项目级与工作空间级配额。

### 4.4 配额设置

#### 4.4.1 手动设置

1. `配额详情 → 编辑配额`。
2. 输入各维度总量。
3. 选择超额策略（见 4.5）。
4. 确认提交，变更入审计日志。

#### 4.4.2 按套餐模板

- 套餐预置配额模板，创建租户时自动应用。
- 模板可由平台管理员在`管理 → 套餐管理`中维护。

| 套餐 | CPU | 内存 | 存储 | 作业数 | 引擎实例 |
| --- | --- | --- | --- | --- | --- |
| 试用 | 10 核 | 40 Gi | 100 Gi | 5 | 3 |
| 标准 | 100 核 | 400 Gi | 1 Ti | 50 | 20 |
| 企业 | 500 核 | 2 Ti | 10 Ti | 200 | 100 |
| 定制 | 协商 | 协商 | 协商 | 协商 | 协商 |

#### 4.4.3 按历史用量推荐

- 系统根据过去 30 天峰值用量推荐配额（峰值 × 1.2）。
- 推荐值仅供参考，须人工确认。

### 4.5 超额策略

当资源使用超过配额时，平台按超额策略处理：

| 策略 | 编码 | 行为 | 适用场景 |
| --- | --- | --- | --- |
| 拒绝提交 | `reject` | 新作业提交被拒，已运行不受影响 | 严格控制成本 |
| 允许超额计费 | `overage_bill` | 允许超额，超额部分按溢价计费 | 弹性需求 |
| 告警不拒绝 | `alert_only` | 仅告警，不拒绝 | 内部租户宽松 |

### 4.6 弹性配额

#### 4.6.1 临时提升

- 场景：大促/月底跑批等峰值时段。
- 操作：`配额详情 → 弹性配额 → 申请临时提升`。
- 须审批：租户管理员申请 → 平台管理员审批。
- 自动回退：到期后自动回退到原配额。

#### 4.6.2 预约提升

- 可提前预约弹性配额（如预约大促期间）。
- 系统自动在预约时段提升配额，到期自动回退。

### 4.7 配额管理 FAQ

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 作业提交报"配额不足" | 当前用量已达配额 | 提升配额或停止其他作业 |
| 配额调整后未生效 | 缓存延迟（< 1 分钟） | 等待或刷新页面 |
| 弹性配额申请被拒 | 平台资源不足 | 联系运维扩容集群 |
| 超额计费账单异常 | 计量延迟 | 联系平台管理员核对 |

## 第5章 安全配置

### 5.1 国密配置

平台支持国密算法 SM2/SM3/SM4，符合 GM/T 0002、GM/T 0004、GM/T 0009 等规范。

#### 5.1.1 国密算法用途

| 算法 | 类型 | 用途 |
| --- | --- | --- |
| SM2 | 非对称 | TLS 证书 / USB Key 登录 / 数字签名 |
| SM3 | 摘要 | 密码哈希 / 文件指纹 / 证书指纹 |
| SM4 | 对称 | 数据加密 / 凭证加密 / 数据库透明加密 |

#### 5.1.2 国密开关配置

路径：`管理 → 安全配置 → 国密`

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| 启用国密 TLS | 控制台与 API 使用 SM2 证书 | 信创环境强制开 |
| 启用国密登录 | 支持 USB Key 登录 | 信创环境强制开 |
| 密码哈希算法 | SM3 / SHA-256 | SM3 |
| 凭证加密算法 | SM4 / AES-256 | SM4 |
| 数据库透明加密 | 启用 SM4 TDE | 关（按需开） |

#### 5.1.3 国密证书管理

- 证书签发：对接国密 CA（如 CFCA、信安世纪）。
- 证书续期：到期前 30 天告警，由运维续期。
- 证书撤销：密钥泄露时撤销并全量轮转。

> 详细技术实现见 `design/安全/国密认证材料/SM2SM3SM4技术实现说明.md`。

### 5.2 安全策略

#### 5.2.1 密码策略

路径：`管理 → 安全配置 → 密码策略`

| 配置项 | 推荐值 | 说明 |
| --- | --- | --- |
| 最小长度 | 12 | 含大小写+数字+符号 |
| 有效期 | 90 天 | 到期强制改密 |
| 历史不重复 | 5 | 不可与最近 5 次重复 |
| 失败锁定 | 5 次失败锁 30 分钟 | 防暴力破解 |
| 弱密码字典 | 启用 | 拒绝常见弱密码 |

#### 5.2.2 会话策略

| 配置项 | 推荐值 | 说明 |
| --- | --- | --- |
| 会话超时 | 8 小时 | 超时自动退出 |
| 单账号并发 | 5 | 同账号最多 5 个会话 |
| IP 白名单 | 可选 | 限制登录 IP |
| 强制 MFA | 管理员强制 | 管理员角色必须绑 MFA |

#### 5.2.3 网络策略

- 租户网络隔离：默认租户间网络全隔离，按需开放白名单。
- 引擎网络隔离：引擎 Pod 仅暴露必要端口。
- 出向控制：可配置出向域名/IP 白名单，防止数据外泄。

### 5.3 审计日志

#### 5.3.1 审计范围

平台对所有关键操作记录审计日志，包含：

- 登录/退出 / 密码修改 / MFA 绑定。
- 租户/用户/角色/配额的增删改。
- 作业提交/停止/删除。
- 数据集成任务的创建/修改/执行。
- 数据集/图表/仪表盘的分享/删除。
- 配置变更 / 证书操作 / 密钥轮转。

#### 5.3.2 审计日志查看

路径：`管理 → 审计日志`

支持按以下维度筛选：

- 时间范围（精确到分钟）。
- 操作人（用户）。
- 操作类型（登录/创建/修改/删除/...）。
- 资源类型（租户/用户/作业/...）。
- 资源 ID。
- 操作结果（成功/失败）。
- 来源 IP。

#### 5.3.3 审计日志字段

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 时间 | 操作时间戳 | `2026-08-18 14:23:15` |
| 操作人 | 用户账号 | `admin@retail-corp` |
| 操作类型 | 标准化操作类型 | `TENANT_FREEZE` |
| 资源类型 | 标准化资源类型 | `TENANT` |
| 资源 ID | 资源唯一标识 | `retail-corp` |
| 资源名称 | 资源显示名 | `某零售集团` |
| 操作结果 | 成功/失败 | `SUCCESS` |
| 来源 IP | 客户端 IP | `10.0.1.23` |
| User-Agent | 客户端 | `Chrome/120` |
| 详情 | 变更前后 JSON | `{"status":"RUNNING→FROZEN"}` |
| 请求 ID | 用于追踪 | `req-abc123` |

#### 5.3.4 审计日志导出

- 支持导出 CSV / Excel，单次最多 10 万条。
- 大量导出须异步任务，完成后邮件通知下载链接。
- 审计日志保留 7 年（合规要求），超期归档冷存储。

#### 5.3.5 审计日志防篡改

- 审计日志写入即不可修改（WORM 存储）。
- 日志哈希链：每条日志含前一条哈希，形成链式结构，篡改可检测。
- 定期对账：每日凌晨自动校验哈希链完整性。

### 5.4 安全配置 FAQ

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 国密 TLS 浏览器不识别 | 浏览器不支持国密 | 安装国密浏览器插件或用信创浏览器 |
| USB Key 登录失败 | 驱动未装 / PIN 错误 | 安装驱动 / 核对 PIN |
| 审计日志查询慢 | 查询范围过大 | 缩小时间范围 / 异步导出 |
| 密码改密失败 | 不满足策略 | 按提示满足复杂度 |
| MFA 绑定后无法解绑 | 管理员强制 | 联系管理员解绑 |

## 第6章 管理员常见问题 FAQ

### 6.1 通用问题

**Q1：忘记管理员密码怎么办？**
A：联系平台管理员（平台运营方）重置；平台管理员忘记须由运维通过命令行重置：
```bash
# 命令示例：重置平台管理员密码
debdp user reset-password --user platform-admin --new-password <新密码>
```

**Q2：管理员离职如何交接？**
A：1) 新管理员创建账号并分配角色；2) 旧管理员禁用账号；3) 旧管理员负责的租户/项目 Owner 变更为新管理员；4) 审计日志保留旧管理员操作记录。

**Q3：能否批量创建用户？**
A：支持 CSV 批量导入，路径`用户管理 → 批量导入`，模板可下载。LDAP/OAuth2 用户自动同步，无需手动创建。

**Q4：租户间数据能否共享？**
A：默认隔离。如需共享，须通过"数据资产流通"流程：上架方上架 → 申请方申请 → 上架方审批 → 平台管理员备案 → 开放访问。详见 `design/详细设计/多平台多租户大数据平台_数据资产流通详细设计_v0.1.md`。

### 6.2 计费相关

**Q5：租户账单在哪里查看？**
A：`管理 → 账单管理`（平台管理员）或`租户详情 → 账单`（租户管理员）。账单按月生成，含 CPU/内存/存储/作业算时/API 调用明细。

**Q6：超额计费如何计算？**
A：超额部分按套餐单价 × 1.5 溢价计算，账单中单列"超额费用"项。

### 6.3 运维相关

**Q7：管理员能否查看租户数据？**
A：默认不可见（数据级权限隔离）。如合规审计需要，须走"特权访问"流程：申请 → 审批 → 限时访问 → 审计记录。

**Q8：如何通知租户新版本上线？**
A：`管理 → 公告管理 → 发布公告`，可按租户/角色/时间定向发布，用户登录后首屏可见。
