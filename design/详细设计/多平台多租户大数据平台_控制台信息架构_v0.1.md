# L5.1 控制台信息架构（IA）· 详细设计（v0.1）

> 归属：多平台多租户大数据平台 · L5 多租户产品层（客户可见控制台）
> 关联：v0.3 控制台原型（本 IA 的源）；L0.11 封装层（层级边界的底层映射）；v0.4 架构总览
> 目标：将控制台原型 v0.3 的导航与页面树，落成**正式信息架构文档**，作为后续 UI 迭代与前端实现的基线。
> 适用版本：基础版✅ / 标准版✅ / 旗舰版✅（全版本开放，对照 §11.5 套餐模块矩阵）

## 1. 设计原则

1. **客户无感知 K8s**：导航与页面只出现业务概念（工作空间/项目/任务/资产），绝不出现 Namespace/Pod/Node/Operator。
2. **顶层隔离 = 工作空间**：所有功能在"当前工作空间"上下文内运作，切换工作空间即切换数据与安全边界。
3. **生产动线清晰**：数据生产（集成/开发）→ 数据治理（目录/标准/质量/血缘/安全）→ 消费运营（分析/运维/账户）单向递进。
4. **双视角分明**：客户视角（工作空间内）与平台运维视角（运营后台）严格分离，后者印证底座封装。
5. **能力可插拔**：智能数据层（向量/知识/LLMOps/网关）作为独立分组，可按套餐显隐。
6. **前端技术栈**：Vue3 + TypeScript（与 frontend/ 工程一致，对照基准 §16.1「控制台原型 v0.4（Vue3，进行中）」），组件库采用 Element Plus，状态管理 Pinia，构建 Vite。

## 2. 信息层级（三层）

```text
平台（Platform）
 └─ 工作空间 Workspace        ← 顶层隔离边界（K8s Namespace + Quota + NetworkPolicy）
     └─ 数据项目 Project       ← 数据加工/消费组织单元（标签 + 存储前缀 + RBAC）
         ├─ 数据集 Dataset     ← Iceberg/Doris 表（= 资产目录条目）
         ├─ 任务/作业 Task      ← 同步任务 / 开发作业 / 调度 DAG
         └─ 资产 Asset         ← 登记、申请、订阅的对象
```

## 4. 页面内部结构范式

各页面统一采用"列表 → 抽屉详情 → 模态表单"三件套：

- **列表/看板**：表格或卡片，支持筛选、搜索、状态标签。
- **抽屉（Drawer）**：点列表行打开，含标签页（概览/成员/配额/项目；元数据/Schema/质量/权限）。右侧滑出，不离开上下文。
- **模态（Modal）**：新建/配置表单，18 类（工作空间/项目/同步/数据源/资产/标准/质量/脱敏/向量/微调/Key/看板/升级套餐等）。
- **模拟运行**：开发/统一 SQL 的"运行/执行"触发逐行日志动画，明确标注"Pod 由 Operator 托管、客户不可见"。

## 5. 双视角（客户 vs 平台运维）

| 视角 | 入口 | 可见范围 | 底层映射 |
| --- | --- | --- | --- |
| 客户 | 工作空间切换器 | 本工作空间内项目/资产/任务/配额 | Namespace + Quota |
| 平台运维 | 运营后台 | 全部租户、集群实例、环境矩阵、营收 | 全集群 K8s 资源 |

> 客户**不持有 kubeconfig、无 K8s API 权限**；运营后台是"K8s 封装层"对平台侧开放的唯一切面，直接印证底座透明封装。

## 6. 页面 ↔ 后端模块映射（闭环校验）

| 页面 | 后端契约 |
| --- | --- |
| 工作空间 / 账户配额 | L0.11 封装层 v0.1 |
| 统一 SQL | L2.7 统一 SQL 网关 v0.1 |
| 数据集成 / 开发 / BI | L2.1 统一存储（被读写）、通用作业调度 |
| 资产目录 | L3.5 资产目录 v0.1 |
| 数据标准/质量/血缘 | L3.1~L3.4 治理中台 v0.1 |
| 安全脱敏 | L3.7 安全脱敏（已规划） |
| 向量库/知识工程/LLMOps/网关 | L4.5 智能数据层 v0.1 |

> 至此，**框架 v0.4 主链路每个客户可见页面均有对应后端契约**，前端与后端对齐闭环。

## 7. 后续迭代基线

- 新增页面须先落此 IA（分组 → 页面 → 内部结构），避免导航膨胀。
- 智能数据层四项可按套餐显隐（旗舰版全开，标准版/基础版全部隐藏，对照 §11.5 套餐模块矩阵：L4.5.3–L4.5.6 在标准版与基础版均为 ❌）。
- 所有"环境/底座/容器"相关术语一律不在客户视角出现，仅在运营后台呈现。
