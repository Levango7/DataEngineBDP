# L5.6 数据资产流通 · 详细设计（v0.1）

> 归属：多平台多租户大数据平台 · L5 多租户产品层（SaaS）
> 对标：Navier（数据资产流通/变现/交换平台）/ 上海数据交易所 / 贵阳大数据交易所
> 关联：L3.5 资产目录（资产来源）；L3.6 主数据（元数据标准）；L5.5 开放API服务目录（数据服务类资产）；L4.5.2 机器学习（模型类资产）；L4.5.5 LLMOps（大模型类资产，可流通）；X2 安全合规（脱敏/出境审查）；§11.5 定价模型（结算与分账）

## 1. 定位与价值

数据资产流通是 L5 多租户产品层的**可选增值模块**（仅旗舰版可选）：将平台内数据集、数据服务、数据模型三类资产统一登记、上架、流通、变现，构建"提供方—平台—消费方"三方市场。

客户价值：
- **资产变现**：数据/服务/模型所有者把闲置资产上架流通，按订阅/交易获得收益分成。
- **按需取数**：消费方在流通目录检索、订阅或一次性购买，免去自建采集与加工链路。
- **等价交换**：同平台租户间互开数据权限，不收费、走内部结算，降低协作摩擦。

平台价值：
- 流通目录与 L3.5 资产目录同源元数据，避免二次登记；安全分级复用 X2。
- 收益分成（默认提供方 80% / 平台 20%）可配置，对接 §11.5 定价模型分账。
- 流通记录上链存证（可选），保证不可篡改与全链路溯源。

## 2. 资产登记与上架

可流通资产四类：
- **数据集**：表/文件，来自 L3.5 资产目录（Iceberg 表或对象存储文件）。
- **数据服务**：API，来自 L5.5 开放API服务目录（按调用计费）。
- **数据模型**：ML 模型，来自 L4.5.2 机器学习（按推理调用或一次性买断）。
- **大模型**：领域大模型/微调模型，来自 L4.5.5 LLMOps（按推理调用、Token 计量或一次性买断；大模型作为高价值资产纳入流通，需额外审查：模型权重安全分级、训练数据合规性声明、出口管制判定）。

上架流程：

```text
┌──── 资产所有者(租户) ────┐
│  选择资产 → 填写登记信息    │
│  (元数据/质量评分/安全分级/  │
│   样例数据/更新频率/描述)    │
└────────────┬────────────┘
             ▼
┌──── 平台审核 ────┐
│  合规审查(对接X2) │  敏感数据要求脱敏规则
│  安全分级复核     │  出境可行性判定
│  质量评分核验     │
└────────────┬────┘
             ▼ (通过)
┌──── 上架到流通目录 ────┐
│  生成资产卡片 + 资产ID    │
│  定价: 所有者定价 或       │
│        平台指导价(§11.5)   │
│  状态: 已上架/可流通        │
└────────────────────────┘
```

资产卡片字段：

| 字段 | 说明 | 来源 |
| --- | --- | --- |
| 资产ID/名称/描述 | 唯一标识与展示 | 登记 |
| 资产类型 | 数据集/数据服务/数据模型 | 登记 |
| 提供方 | 源租户名称与ID | 自动 |
| 质量评分 | 0-100，由 L3.5 质量评估产出 | L3.5 |
| 安全分级 | 公开/内部/敏感 | X2 |
| 更新频率 | 实时/小时/日/周/月/静态 | 登记 |
| 样例数据 | 前 N 行或 API 样例响应 | 登记 |
| 价格 | 计费方式与单价 | §11.5 |
| 订阅者数 | 当前订阅/购买方数量 | 运行时统计 |

## 3. 流通模式

四种流通模式覆盖拉/推/双向/付费场景：

```text
┌─────────────────────────────────────────────────┐
│  ① 订阅(拉)    消费方定期拉取增量   ← 数据集     │
│  ② 推送(推)    提供方事件驱动推送   ← 实时数据   │
│  ③ 交换(双向)  两租户互开权限,不收费 ← 协作场景  │
│  ④ 交易(付费)  一次性买断/按量付费  ← 高价值资产 │
└─────────────────────────────────────────────────┘
```

| 模式 | 流向 | 计费 | 适用场景 | 实现要点 |
| --- | --- | --- | --- | --- |
| 订阅 | 提供方→消费方(定期拉) | 按月/按量 | 数据集增量同步 | 消费方配置拉取周期，经 L2.1 统一存储读增量 |
| 推送 | 提供方→消费方(事件触发) | 按次/按量 | 实时事件、告警 | 提供方注册 webhook/Kafka topic，事件即推 |
| 交换 | 双向互开 | 免费(等价) | 集团内兄弟公司协作 | 双方确认交换协议，互授数据集只读权限 |
| 交易 | 提供方→消费方(一次性/按量) | 一次性买断/按量 | 高价值数据集、ML 模型 | 下单→扣费→交付访问凭证或模型文件 |

## 4. 变现与结算

计费方式：按次 / 按月 / 按量（行数或字节数）/ 一次性买断，由资产卡片定价字段指定。

收益分成（默认可配置）：
- 提供方得 **80%**，平台抽成 **20%**。
- 内部租户间流通走**内部结算**：成本系数 0.3，对接 L5.4 多租户计费，仅记成本不真扣费。

结算流程：

```text
消费方扣费 ──▶ 平台分账 ──▶ 提供方入账 ──▶ 月度对账单
   (订单)      (20%抽成)     (80%入账)      (双方可见)
```

> 内部租户间交换/订阅走 L5.4 内部结算通道，不计入外部分账；跨租户交易走外部结算与对账单。

## 5. 安全与合规

- **安全分级**：
  - 公开：可直接流通，无需审批。
  - 内部：需平台审批后流通。
  - 敏感：必须脱敏后流通，脱敏规则对接 X2 安全合规。
- **数据出境**：敏感数据禁止出境，出境审查对接 X2；内部/公开数据出境需审查通过。
- **存证**：流通记录上链（可选，对接区块链存证服务），保证登记/订阅/交易/结算记录不可篡改。
- **溯源**：每次流通记录可追溯链路：提供方 → 消费方 → 时间 → 量 → 价格 → 存证哈希。

## 6. 接口契约

```text
POST /api/market/v1/assets/register        { assetType, sourceRef, metadata, securityLevel, sample } → { assetId, status }
GET  /api/market/v1/catalog                { type?, q?, page } → [{ assetId, card... }]
POST /api/market/v1/assets/{id}/subscribe  { consumer, period, pullConfig } → { subscriptionId }
POST /api/market/v1/assets/{id}/exchange   { peerTenant, assetIdB, agreement } → { exchangeId }
POST /api/market/v1/assets/{id}/purchase   { consumer, billingMode, qty? } → { orderId, settlementId }
GET  /api/market/v1/lineage/{assetId}      → [{ provider, consumer, time, volume, price, hash }]
POST /api/market/v1/settle/monthly         { tenant, month } → { bills[], totalProvider, totalPlatform }
```

> 所有接口经 L5.5 开放API网关鉴权；数据实际传输经 L2.1 统一存储或 L5.5 API，不直接暴露对象接口。

## 7. 多环境对照

流通目录本身**环境无关**（元数据 + 关系型存储）；数据实际传输经 L2.1 统一存储或 L5.5 API，随环境变。信创环境需验证存证服务国产化。

| 环境 | 流通目录 | 数据传输 | 存证服务 |
| --- | --- | --- | --- |
| 信创 | 同一套目录服务 | L2.1 国产对象存储 / L5.5 API | 国产区块链存证（需验证） |
| 本地数据中心 | 同上 | Ceph/MinIO + L5.5 API | 可选本地链或关闭 |
| 公有云 VM | 同上 | 客户云对象存储 + L5.5 API | 客户提供链服务或关闭 |
| 私有云 | 同上 | 私有云对象存储 + L5.5 API | 厂商链或关闭 |

> 关键约束：流通目录与分账逻辑四环境一致；存证服务为可选增强，关闭时仅落库不上链，不影响流通主流程。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 敏感数据泄露 | 合规事故、平台声誉 | 强制脱敏（对接 X2）+ 出境审查 + 安全分级强制校验 |
| 定价纠纷 | 提供方与消费方争议 | 平台指导价兜底（§11.5）+ 仲裁机制 + 流通存证可举证 |
| 资产质量造假 | 消费方受损、市场失信 | 质量评分（L3.5 自动）+ 消费方评分双重约束，低分资产下架 |
| 链上存证性能 | 高频流通上链延迟 | 批量上链 + 异步落链，链下先落库保证可用 |
| 跨租户越权访问 | 数据泄露 | 资产权限按 tenant 隔离 + NetworkPolicy + 访问审计 |

## 9. 与 UI 的对应
