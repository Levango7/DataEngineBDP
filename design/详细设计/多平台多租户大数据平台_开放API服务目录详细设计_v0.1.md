# L5.5 开放 API / 服务目录 · 详细设计（v0.1）

> 归属：多平台多租户大数据平台 · L5 多租户产品层（SaaS，仅旗舰版）
> 对标：AWS API Gateway + Marketplace / 阿里云 API 市场 / Kong Dev Portal
> 关联：X4 API网关（APISIX）；X1 统一身份权限（Keycloak）；L4.5.6 领域大模型接口；§11.5 定价模型；L3.5 资产目录

## 1. 定位与价值

将平台数据能力封装为 **REST/gRPC API**，经 APISIX 网关对外暴露；配套**服务目录**支持浏览、搜索、订阅、评分，形成"数据即 API、API 即资产"的开放生态。

客户价值：
- 上下游系统/外部合作伙伴**自助订阅**数据 API，无需人工对接。
- 大模型推理（L4.5.6）、Trino 查询（L2.4）、Doris 在线（L2.5）统一以 API 形式输出。
- SLA 等级 + 计费策略透明，按次/按量/按月包灵活选。

平台价值：
- 发布流程标准化（OpenAPI Spec / gRPC Proto），安全审核与审批内嵌。
- 计量计费自动汇聚到 §11.5，月度出账闭环。
- 仅旗舰版开放，强化高端版本差异化壁垒。

## 2. 总体架构

```text
┌──────── 消费者（同平台租户 / 外部系统） ────────┐
│   浏览目录 → 申请订阅 → 持 AK/SK 调用           │
└──────────────────────┬─────────────────────────┘
                       ▼
┌──────── X4 APISIX 网关（认证/限流/计量/路由） ────────┐
│  Keycloak 校验 JWT/API Key → 插件链(限流/熔断/计量)    │
└──────┬──────────────┬──────────────┬──────────────┬──┘
       ▼              ▼              ▼              ▼
   L2.4 Trino     L2.5 Doris     L4.5.6 大模型   自定义函数
   (交互查询)     (在线服务)     (推理接口)      (UDF/UDAF)
                       ▲
                       │ 注册/路由下发
┌──────── API 发布管理 + 服务目录 ────────┐
│  定义→安全审核→审批→发布→版本→监控→下线  │
│  目录：分类/标签/全文+语义搜索/评分       │
└──────────────────────────────────────────┘
```

## 3. API 发布流程（状态机）

```text
[定义] ──提交 OpenAPI Spec / gRPC Proto──> [安全审核]
[安全审核] ──SQL注入/XSS/越权扫描通过──> [审批]
[安全审核] ──扫描失败──> [驳回(回退定义)]
[审批] ──租户管理员通过──> [发布到网关]
[审批] ──驳回──> [驳回]
[发布到网关] ──APISIX 路由+插件下发──> [运行中]
[运行中] ──灰度/蓝绿版本切换──> [运行中]
[运行中] ──监控异常/主动下线──> [下线通知消费者]
[下线] ──优雅降级(宽限期)──> [归档]
```

发布要素：
- **契约**：REST 用 OpenAPI 3.0 Spec，gRPC 用 Proto；版本号语义化（v1.2.3）。
- **安全审核**：自动扫描 SQL 注入、XSS、越权（跨租户访问路径）、敏感字段泄露。
- **审批**：租户管理员单签；涉敏感数据 API 加平台运营二审。
- **网关下发**：APISIX 路由 + 插件链（限流/熔断/计量/日志/重写）一次性下发。
- **版本管理**：灰度按消费者权重切流；蓝绿整版本切换；旧版本宽限期 30 天后下线。

## 4. 服务目录

可浏览（分类/标签）、可搜索（全文 + 语义向量召回）、可订阅（申请 AK/SK）、可评分（5 星 + 评论）。

API 条目字段：

| 字段 | 说明 |
| --- | --- |
| apiId / 名称 / 描述 | 唯一标识与展示信息 |
| 版本 | 当前版本 + 历史版本列表 |
| 提供方租户 | 发布方 tenantId |
| 消费者列表 | 已订阅消费者（租户/外部系统） |
| 调用统计 | 近 7/30 日调用量、成功率、P99 延迟 |
| SLA 等级 | 铂/金/银（可用性 + 响应承诺） |
| 计费策略 | 按次/按量/按月包（对接 §11.5） |
| 分类 / 标签 | 目录归类与检索维度 |
| 契约 URL | OpenAPI Spec / Proto 托管地址 |

> API 即资产：发布同步注册到 L3.5 资产目录，资产下线联动 API 下线。

## 5. 消费者订阅与调用

订阅流程：
```text
消费者浏览目录 → 选中 API → 提交订阅申请(含用途/配额期望)
   → 提供方审批 → 经 Keycloak 发放 AK/SK(范围限定该 API)
   → 消费者持 AK/SK 调用 → 网关认证/限流/计量 → 后端服务
```

调用链路与认证：
- **认证方式**：API Key（OAuth2 Client Credentials）或 JWT，均经 Keycloak 校验。
- **网关拦截**：APISIX 插件链依次做认证 → 租户隔离 → 限流 → 熔断 → 计量 → 转发。
- **后端路由**：按 API 配置路由到 Trino / Doris / 大模型 / 自定义函数。
- **租户隔离**：网关层强制注入 `consumer_tenant_id`，后端按此过滤，杜绝跨租户越权。

## 6. 计量计费

网关每次调用记录计量明细，按计费策略汇总到 §11.5，月度出账。

计量数据模型：
```text
CallMetric {
  callId        // 唯一调用 ID
  apiId, version
  consumerTenantId, providerTenantId
  timestamp
  latencyMs     // 端到端延迟
  requestBytes, responseBytes
  statusCode
  costStrategy  // by_call | by_bytes | monthly_package
  costAmount    // 本次折算金额
}
```

计费策略：
- **按次**：每次调用固定单价，适合查询类 API。
- **按量**：按返回数据量计价，适合导出/推理类 API。
- **按月包**：包月配额，超量走 §11.5 超量计费阶梯单价。
- **出账**：月度按消费者租户汇聚 → 推送账单 → 关联订单结算。

## 7. 接口契约

```text
POST /api/l5/v1/apis/publish           { spec, runtime, sla, billing } → apiId
GET  /api/l5/v1/catalog                { category?, keyword?, page } → [ApiEntry]
POST /api/l5/v1/apis/{apiId}/subscribe { purpose, quotaExpect } → subscriptionId
POST /api/l5/v1/subscriptions/{subId}/approve { approve, reason } → { ak, sk }
POST /api/l5/v1/apis/{apiId}/invoke    { payload, headers } → { result }   // 经网关
GET  /api/l5/v1/apis/{apiId}/stats     { range } → { calls, successRate, p99, cost }
```

> `invoke` 实为经 APISIX 网关转发的逻辑契约；真实调用走网关域名，不直连此管理面。

## 8. 多环境对照

| 环境 | API 网关（APISIX） | 服务目录 | 后端服务 | 说明 |
| --- | --- | --- | --- | --- |
| 信创 | 自建（ARM 镜像验证） | 环境无关 | 随环境变 | 需验证 APISIX ARM 镜像兼容 |
| 本地数据中心 | 自建 | 环境无关 | 随环境变 | 裸金属/虚机部署 |
| 公有云 VM | 自建（客户提供 VM） | 环境无关 | 随环境变 | 不用云托管网关，保持可迁移 |
| 私有云 | 自建 | 环境无关 | 随环境变 | 厂商私有云 VM |

> 关键约束：APISIX 四环境均自建，绝不使用云托管 API 网关——保持配置可迁移、不锁云。

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| API 滥用/突发流量 | 后端被打垮 | 网关限流（令牌桶）+ 熔断 + 消费者配额 |
| 密钥泄露 | 越权调用 | Keycloak 定期轮换 AK/SK + 异常调用告警吊销 |
| 跨租户越权 | 数据泄露 | 网关层强制租户隔离 + 后端按 consumer_tenant_id 过滤 |
| 服务下线影响消费者 | 业务中断 | 提前 30 天通知 + 旧版本宽限期 + 优雅降级 |
| 契约不兼容变更 | 消费者报错 | 语义化版本 + 灰度切流 + 旧版本并存 |
| 信创 ARM 兼容 | 网关无法运行 | 预先验证 APISIX ARM 镜像 + 备选 Kong 信创版 |
