  - L4.1 数据集成无法从 L3.1 元数据自动获取源/目标 schema，需用户手工填写，易错且违反"治理前置"原则。

  - L4.4 BI 建数据集时无法从 L3.5 获取已发布视图与字段敏感级别，可能绕过脱敏。
- **修复建议**：
  1. 在治理中台文档"跨组件一致性"表新增"L4 层消费"行，明确：
     - L4.1 调 `/api/meta/v1/entities` 获取 schema
     - L4.2 调 `/api/dq/v1/rules/{id}/run` 作为 DAG 质量校验节点
     - L4.3 调 `/api/catalog/v1/assets` 做表名/字段补全
     - L4.4 调 `/api/catalog/v1/assets/{id}` 获取数据集元模型与敏感级别
  2. 在 4 份 L4 文档的"关联"行补充对 L3 治理 API 的引用。
