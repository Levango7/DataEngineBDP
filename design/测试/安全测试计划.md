## 1. 测试目标

### 1.1 总体目标

通过系统化安全测试，验证多平台多租户大数据平台满足 OWASP Top 10 防护要求、等保三级技术要求、国密合规要求，识别并消除安全漏洞，为等保三级测评与商用上线提供安全放行依据。

### 1.2 量化目标

| 维度 | 目标 | 度量 |
| --- | --- | --- |
| OWASP Top 10 覆盖 | 10/10 全测 | 测试用例覆盖矩阵 |
| 高危漏洞 | 0 | SAST + DAST + SCA + 人工 |
| 中危漏洞 | ≤ 5 且全部有缓解措施 | 评审通过 |
| 等保三级控制项 | 100% 落地验证 | 控制项验证表 |
| 国密合规 | 信创环境全栈国密 | 国密自检清单 |
| 渗透测试 | 无控制绕过 | 第三方渗透报告 |
| 镜像漏洞 | 0 高危，≤ 5 中危 | Trivy 扫描 |
| 依赖漏洞 | 0 高危 | SCA + SBOM |
| 多租户隔离 | 无越权 | 跨租户用例 100% 通过 |

### 2.2 等保三级安全测试要求

| 层面 | 控制项 | 测试方法 | 通过标准 |
| --- | --- | --- | --- |
| 网络安全 | 边界防护 | 端口扫描 + NetworkPolicy 验证 | 仅暴露必要端口，租户间网络隔离 |
| 网络安全 | 访问控制 | RBAC + ABAC 越权测试 | 最小权限，无越权 |
| 网络安全 | 安全审计 | 审计日志完整性测试 | 三类日志 180 天 WORM，防篡改 |
| 网络安全 | 入侵防范 | HIDS + Falco 规则验证 | 异常行为 5 分钟内告警 |
| 主机安全 | 身份鉴别 | OS 基线扫描 + SSH 密钥校验 | 无弱密码，MFA 启用 |
| 主机安全 | 入侵防范 | 漏洞扫描 + 补丁核查 | 无高危漏洞，补丁 30 天内 |
| 应用安全 | 通信安全 | TLS1.3/TLCP 强制 + 证书校验 | 全链路加密，证书有效 |
| 应用安全 | 入侵防范 | WAF + RASP + 限流测试 | 注入/CC 攻击拦截率 > 99% |
| 数据安全 | 数据完整性 | SM3/SHA-256 哈希校验 | 数据可校验，防篡改 |
| 数据安全 | 数据保密性 | 字段级加密 + 传输加密 + 脱敏 | 敏感字段加密存储，传输加密 |
| 数据安全 | 数据备份恢复 | 备份完整性 + 恢复演练 | RTO < 4h，RPO < 1h |

### 2.3 国密合规测试

| 算法 | 用途 | 测试项 | 通过标准 |
| --- | --- | --- | --- |
| SM2 | 非对称加密/签名 | 证书签名、密钥交换、TLS 握手 | 信创环境全启用 |
| SM3 | 哈希 | 数据完整性、口令哈希、证书指纹 | 替代 SHA-256 |
| SM4 | 对称加密 | 字段级加密、传输加密、存储加密 | 替代 AES |
| TLCP | 传输安全 | 双证书握手、国密通道 | 信创环境强制 |
| SM2/SM3/SM4 一致性 | 互操作 | 与国密产品互通测试 | 通过商密产品检测 |

### 4.2 多租户越权专项（S-06）

- **垂直越权**：普通用户 Token 调用管理员接口，预期 403。
- **水平越权**：租户 A Token 访问租户 B 资产/作业/数据，预期 403。
- **IDOR**：枚举资产 ID、作业 ID、租户 ID，预期 403。
- **Token 重放**：过期 Token、撤销 Token、被改 Token，预期 401。
- **租户注入**：Header/Body 注入他租户 ID，预期 403。
- **网络绕过**：跨 namespace 直连服务，预期 NetworkPolicy 拦截。

### 4.3 国密合规自检（S-08）

- 检测信创环境是否强制 SM2/SM3/SM4 + TLCP，禁用 RSA/SHA-1/AES。
- 检测证书链是否为商密证书，签名算法 SM2withSM3。
- 检测字段级加密是否使用 SM4-CBC/GCM，密钥由 KMS 托管。
- 检测口令哈希是否使用 SM3 + 加盐 + 迭代 ≥ 10000。
- 输出《国密合规性自检清单》报告，参见 `design/安全/国密认证材料/国密合规性自检清单.md`。

## 5. 测试环境

### 5.1 环境规格

- **DAST/渗透环境**：独立 staging 集群，与生产同规格，数据脱敏后镜像。
- **SAST/SCA 环境**：CI 流水线，无需独立集群。
- **国密测试环境**：信创环境，openEuler + 国产 JDK + 国密证书。
- **多租户测试数据**：50 租户，每租户独立 namespace + 独立 Token + 独立数据。

### 5.2 数据安全要求

- 测试数据严禁包含真实敏感数据，全部使用脱敏或合成数据。
- 渗透测试产生的攻击流量不得外泄，测试环境网络隔离。
- 测试发现的高危漏洞 24h 内修复，未修复禁止合并与发布。

## 7. 结果分析与报告

### 7.1 报告内容

- 测试范围 + 工具 + 时间 + 环境。
- OWASP Top 10 覆盖矩阵 + 每项结论。
- 等保三级控制项验证表 + 每项证据。
- 国密合规自检清单 + 每项结论。
- 漏洞清单（编号/级别/位置/复现/修复/复测）。
- 通过/未通过结论 + 放行/阻断建议。

### 7.2 通过标准

- 高危漏洞 = 0，中危 ≤ 5 且有缓解。
- OWASP Top 10 全部覆盖且结论为"已防护"。
- 等保三级控制项 100% 验证通过。
- 国密合规自检信创环境全项通过。
- 渗透测试无控制绕过。

### 7.3 漏洞分级与处置时限

| 级别 | 定义 | 处置时限 |
| --- | --- | --- |
| 高危 | RCE/SQL 注入/越权/数据泄露 | 24h 内修复 |
| 中危 | XSS/CSRF/信息泄露/弱配置 | 7d 内修复 |
| 低危 | 缺失 Header/轻微信息泄露 | 30d 内修复 |
| 信息 | 加固建议 | 评估后决定 |

## 8. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
| --- | --- | --- | --- |
| DAST 误报多 | 高 | 排查成本 | 人工确认 + 白名单 + 持续调优规则 |

| 测试数据脱敏不彻底 | 低 | 合规风险 | 严格合成数据 + 审计抽查 |
