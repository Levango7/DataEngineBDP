## 1. 测评准备目标

### 1.1 总体目标

为等保三级测评做好全面准备，确保测评机构能够顺利开展测评工作，测评材料齐全、技术措施到位、整改项闭环，争取一次性通过测评。

### 1.2 准备原则

1. **材料齐全**：测评材料覆盖定级、制度、技术、运维、人员全维度。
2. **技术到位**：技术安全措施全部落地并验证，整改项全部闭环。
3. **配合到位**：测评期间配合测评机构工作，提供必要环境与权限。
4. **时间可控**：按测评计划准备，避免临时抱佛脚。

## 3. 技术准备清单

### 3.1 环境准备

- [ ] 测评环境就绪：与生产同规格的 staging 环境。
- [ ] 测评账号就绪：测评机构专用账号 + 最小权限。
- [ ] 测评工具就绪：端口扫描、漏洞扫描、配置扫描工具。
- [ ] 测评网络就绪：测评机构 VPN + 跳板机。
- [ ] 测评窗口就绪：与业务方确认测评窗口。

### 3.2 技术措施验证

- [ ] 网络隔离验证：跨租户访问被拦截。
- [ ] 访问控制验证：越权访问被拒绝。
- [ ] 通信加密验证：TLS1.3/TLCP 全链路加密。
- [ ] 身份鉴别验证：MFA 强制启用。
- [ ] 安全审计验证：审计日志 180 天 WORM。
- [ ] 入侵防范验证：WAF + HIDS + 镜像扫描。
- [ ] 数据安全验证：加密 + 哈希 + 脱敏。
- [ ] 备份恢复验证：RTO < 4h，RPO < 1h。

### 3.3 整改项闭环

- [ ] P0 高危整改项全部闭环（R-001 ~ R-004）。
- [ ] P1 中危整改项全部闭环（R-005 ~ R-010）。
- [ ] P2 低危整改项全部闭环或有缓解措施（R-011 ~ R-015）。
- [ ] 整改复测全部通过。

## 4. 测评流程

### 4.1 测评阶段

| 阶段 | 内容 | 工期 | 责责 |
| --- | --- | --- | --- |
| 准备 | 材料准备 + 环境准备 + 整改闭环 | 30d | 安全组 |
| 预沟通 | 与测评机构预沟通 + 资料预审 | 5d | 安全组 |
| 正式测评 | 测评机构正式测评 | 30d | 测评机构 |
| 整改 | 测评发现问题整改 | 15d | 安全组 + 各组 |
| 复测 | 测评机构复测 | 10d | 测评机构 |
| 出报告 | 测评机构出具测评报告 | 10d | 测评机构 |

### 4.2 测评配合

- **配合人**：安全组指定专人配合测评机构。
- **响应时限**：测评期间问题响应 ≤ 4h，紧急问题 ≤ 1h。
- **权限管理**：测评账号权限最小化，测评结束立即收回。
- **数据保护**：测评期间产生的数据测评结束立即删除。

## 5. 测评前自检

### 5.1 自检清单

- [ ] 定级报告完成 + 专家评审通过。
- [ ] 备案完成 + 备案证明取得。
- [ ] 安全管理制度完成 + 全员培训留档。
- [ ] 技术安全措施全部落地 + 验证通过。
- [ ] 整改项全部闭环 + 复测通过。
- [ ] 安全测试报告完成 + 高危漏洞清零。
- [ ] 渗透测试报告完成 + 无控制绕过。
- [ ] 应急预案完成 + 演练留档。
- [ ] 测评环境就绪 + 测评账号就绪。
- [ ] 测评机构选定 + 合同签订。

### 5.2 自检报告

- 自检完成后出《测评准备自检报告》。
- 自检报告含：材料清单完成度、技术措施落地度、整改项闭环度、自检结论。
- 自检结论为"就绪"方可启动正式测评。

---

## 6. 测评机构选择

### 6.1 选择标准

- 具备公安部颁发的网络安全等级保护测评机构推荐证书。
- 具备大型数据平台测评经验。
- 具备信创环境测评能力。
- 服务响应及时，口碑良好。

### 6.2 合作流程

1. 调研候选测评机构（至少 3 家）。
2. 评估资质、经验、报价。
3. 确定测评机构 + 签订合同 + 保密协议。
4. 预沟通 + 资料预审。
5. 正式测评 + 整改 + 复测 + 出报告。

---

## 7. 测评后工作

### 7.1 测评报告归档

- 测评报告原件归档至安全组档案。
- 测评报告电子版归档至 `design/v2.0/Phase1/安全合规/`。
- 备案证明归档。

### 7.2 持续合规

- 每年至少 1 次等保三级测评。
- 测评发现问题纳入整改清单，闭环管理。
- 重大变更触发专项测评或重新测评。
