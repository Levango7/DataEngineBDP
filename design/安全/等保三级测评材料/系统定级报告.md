## 1. 定级背景

### 1.1 定级依据

- 《中华人民共和国网络安全法》第二十一条：国家实行网络安全等级保护制度。
- GB/T 22240-2020《信息安全技术 网络安全等级保护定级指南》。
- GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》。
- GB/T 28448-2019《信息安全技术 网络安全等级保护测评要求》。

### 1.2 定级对象

- **定级对象**：多平台多租户大数据平台。
- **运营单位**：平台运营方。
- **服务对象**：政企客户、行业客户、内部业务线。
- **业务类型**：数据采集、存储、计算、分析、服务、治理一体化平台。

## 2. 业务重要性分析

### 2.1 业务信息类型

| 信息类型 | 重要性 | 说明 |
| --- | --- | --- |
| 客户身份信息 | 重要 | 包含企业信息、用户身份、认证凭据 |
| 业务数据 | 重要 | 客户业务数据，含敏感字段 |
| 系统配置 | 重要 | 平台配置、密钥、证书 |
| 审计日志 | 重要 | 操作审计、安全审计 |
| 公开信息 | 一般 | 平台介绍、文档 |

### 2.2 业务服务类型

| 服务类型 | 重要性 | 说明 |
| --- | --- | --- |
| 数据处理服务 | 重要 | 数据采集、存储、计算、分析 |
| 数据服务 | 重要 | 数据查询、API 服务、数据共享 |
| 平台管理服务 | 重要 | 租户管理、用户管理、权限管理 |
| 运维服务 | 重要 | 监控、告警、运维操作 |

### 2.3 受侵害客体分析

| 客体 | 受侵害程度 | 说明 |
| --- | --- | --- |
| 公民、法人合法权益 | 严重 | 数据泄露导致权益受损 |
| 社会秩序 | 严重 | 大规模数据泄露影响社会稳定 |
| 国家安全 | 一般（不直接） | 不直接涉及国家安全，但部分客户数据敏感 |

### 2.4 受侵害程度判定

- **公民、法人合法权益**：严重损害（数据泄露、业务中断）。
- **社会秩序**：严重损害（大规模数据泄露影响社会稳定）。
- **国家安全**：不构成损害（不直接涉及国家秘密）。

---

## 3. 定级结果

### 3.1 定级矩阵

依据 GB/T 22240-2020 定级矩阵：

| 受侵害客体 | 一般损害 | 严重损害 | 特别严重损害 |
| --- | --- | --- | --- |
| 公民、法人合法权益 | 一级 | 二级 | 三级 |
| 社会秩序 | 二级 | 三级 | 四级 |
| 国家安全 | 三级 | 四级 | 五级 |

### 3.2 定级结论

- **业务信息安全保护等级**：第三级（社会秩序严重损害）。
- **业务服务安全保护等级**：第三级（社会秩序严重损害）。
- **系统定级**：**第三级**。

### 3.3 定级理由

1. 平台承载多租户业务数据，涉及政企客户核心数据，数据泄露将严重损害客户合法权益与社会秩序。
2. 平台作为数据基础设施，业务中断将影响多个客户的业务运行，严重损害社会秩序。
3. 平台不直接涉及国家秘密，不构成对国家安全的损害。
4. 综合判定为第三级，符合 GB/T 22240-2020 定级要求。

## 4. 系统描述

### 4.1 系统边界

- **物理边界**：客户机房 + 云厂商机房（VM + 块存储 + 网络）。
- **网络边界**：K8s 集群 + Ingress 出口 + 数据库 + 引擎 + 对象存储。
- **逻辑边界**：平台控制面 + 数据面 + 引擎层 + 工具层 + 治理层 + 智能层。

### 4.2 系统组成

| 层 | 组件 | 数量 |
| --- | --- | --- |
| L0 基础设施 | K8s 集群、机器供应、容器存储、网络 | 8 |
| L1 封装层 | 鉴权网关、API 网关、限流、配置中心 | 6 |
| L2 引擎层 | Spark、Flink、Trino、Doris、Iceberg、Kafka | 12 |
| L3 治理层 | 元数据、资产目录、主数据、质量、血缘 | 8 |
| L4 工具层 | 数据集成、调度、IDE、BI、标签、ML | 10 |
| X 横切层 | 监控、安全、运维、弹性 | 6 |

### 4.3 系统服务

- 数据采集与集成（批量、实时、文件、API）。
- 数据存储与管理（湖仓集一体、多模型、时序）。
- 数据计算与分析（批、流、交互、OLAP、机器学习）。
- 数据治理与资产化（元数据、质量、血缘、目录、主数据）。
- 数据服务与共享（API、BI、标签、画像、数据流通）。
- 平台管理与运维（租户、用户、权限、监控、告警、计量）。

## 5. 定级备案

### 5.1 备案流程

1. 确定定级对象与等级（本报告）。
2. 编制定级报告（本报告）。
3. 专家评审定级报告。
4. 提交公安机关备案（30 个工作日内）。
5. 公安机关审核出具备案证明。

### 5.2 备案材料

- 系统定级报告（本报告）。
