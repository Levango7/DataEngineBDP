## 1. 自检目标

### 1.1 总体目标

通过国密合规性自检，全面验证平台在信创环境的国密算法使用、密码产品合规、密码应用合规情况，确保通过商用密码应用安全性评估（密评）。

### 1.2 自检原则

1. **全栈覆盖**：从算法、协议、产品、应用四个维度全面自检。
2. **量化判定**：每项自检有明确判定标准与证据。
3. **闭环管理**：不符合项有整改方案与跟踪。
4. **可追溯**：自检结果留档，可追溯。

## 3. 自检方法

### 3.1 代码扫描

- 工具：Semgrep + 自研规则。
- 范围：全平台后端代码 + 前端代码 + 配置文件。
- 检测：禁用算法出现、必用算法缺失、硬编码密钥。

### 3.2 配置审计

- 工具：kube-bench + 自研脚本。
- 范围：K8s 配置 + Nginx 配置 + 应用配置。
- 检测：协议配置、证书配置、密钥配置。

### 3.3 接口测试

- 工具：自研脚本 + 抓包工具。
- 范围：身份认证接口 + API 签名接口 + 传输接口。
- 检测：签名算法、加密算法、协议握手。

### 3.4 数据库扫描

- 工具：自研脚本。
- 范围：用户表 + 敏感字段表 + 日志表。
- 检测：敏感字段加密、口令哈希算法。

### 3.5 证书检查

- 工具：openssl + 国密工具。
- 范围：服务端证书 + CA 证书。
- 检测：签名算法、密钥算法、证书链。

## 5. 不符合项整改

### 5.1 整改流程

1. 识别不符合项，记录编号、内容、级别。
2. 制定整改方案，明确负责人与计划完成时间。
3. 整改实施，记录整改过程。
4. 整改验证，复测确认通过。
5. 闭环管理，更新本清单。

### 5.2 整改时限

| 级别 | 时限 |
| --- | --- |
| 高 | 7d 内 |
| 中 | 15d 内 |
| 低 | 30d 内 |

## 6. 自检报告

### 6.1 报告内容

- 自检范围 + 方法 + 时间。
- 自检清单 + 每项结果与证据。
- 不符合项与整改。
- 综合结论。

### 6.2 报告归档

- 自检报告归档至 `design/安全/国密认证材料/`。
- 自检报告作为密评材料的一部分。

---

## 7. 持续合规

### 7.1 定期自检

- 每季度一次国密合规性自检。
- 重大变更触发专项自检。
- 信创环境每次构建触发自动化自检（C-001 ~ C-013）。

### 7.2 持续监控

- Falco 规则监控禁用算法出现。
- 代码扫描 CI 强制门禁。
- 配置审计定期执行。
