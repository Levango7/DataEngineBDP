## 第1章 实施总览

### 1.1 V2.0 总体里程碑

V2.0 基于 PRD 第 5.2 节的 5 个 Phase 划分，映射为 4 个发布里程碑（alpha → beta → rc → ga），并新增 Phase 0 前置依赖确认阶段，总工期 9 个月（2026-08-15 ~ 2027-05-10，含 Phase 0 前置 2 周 + Phase 4 测评收尾 8 周）。
