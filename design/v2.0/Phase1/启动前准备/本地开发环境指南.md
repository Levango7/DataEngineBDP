## 第1章 概述

### 1.1 文档目标

Phase 1a 批次 1 共 8 个任务，其中 6 个任务不依赖 K8s 集群即可在本地开发环境完成开发、单元测试与轻量集成验证。本文档为这 6 个任务提供统一的本地开发环境搭建指南，覆盖：

- 环境前置条件核对
- Java/Go 组件（已有 Docker 镜像）的容器化启动
- Python 组件（无 Docker 镜像）的本地 Python 直启动
- 中间件环境启动
- 6 个非 K8s 任务的本地开发方式
- 调试技巧与已知限制

### 1.2 本地开发环境组成

本地开发环境分为两部分，分别承担不同语言组件的运行职责：

表：1-1 本地开发环境组成对照表

| 组成部分 | 承载组件 | 运行方式 | 适用任务 |
| --- | --- | --- | --- |
| Java/Go 组件 | encaps-layer、sql-gateway、catalog、rule-engine | Docker 容器（已有镜像） | T012、T014、T022 |
| Python 组件 | asset-exchange、business-portal、open-api-catalog、industry-templates、knowledge-engine、llmops | 本地 Python 直运行（无 Docker 镜像） | T008 |
| 中间件环境 | Kafka、Milvus、NebulaGraph、MySQL、PostgreSQL、MinIO、ES、Redis、Flink 等 14 个服务 | Docker Compose | T008、T014、T018 |
| 纯文档/模板任务 | 等保整改文档、金融模板 DDL/DAG/Dashboard | 文件编辑器 + Git | T000、T018 |

6 个 Python 组件因网络限制无法拉取 `python:3.11-slim` 基础镜像构建 Docker 镜像，改用本地 Python 3.14.3 直接运行。每个组件通过环境变量指定端口与运行参数。

| 组件 | 默认端口 | 启动命令 | 环境变量 | 工作目录 |
