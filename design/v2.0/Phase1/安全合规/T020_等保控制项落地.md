## 第3章 技术整改落地实现（13 项，36 人天）

### 3.1 R01 rule-engine Mock 清零 + L3.7 脱敏规则真实执行 + 行级权限联动

#### 3.1.1 落地目标

将 rule-engine 组件规则执行器从返回 SIMULATED 占位结果改为真实执行脱敏规则，L3.7 数据安全模块脱敏规则经 GitOps 版本化配置，运行时由 rule-engine 引擎执行，X1 ABAC 层根据脱敏结果做行级权限联动判定，消除应用-2（访问控制）高风险差距。

#### 3.1.2 差距根因

rule-engine 组件 `platform/rule-engine/src/main/java/com/shuqing/bigdata/ruleengine/engine/` 中规则执行器返回 SIMULATED 占位结果，L3.7 数据安全模块脱敏规则依赖 rule-engine 执行，导致脱敏规则无法真实生效，敏感数据（如身份证号、手机号）可能以明文展示给无权用户。

#### 3.1.3 落地实现

##### 3.1.3.1 rule-engine Mock 清零

改造 `MaskRuleExecutor.execute()` 方法，从返回 SIMULATED 改为真实执行脱敏规则，支持正则脱敏、哈希脱敏、掩码脱敏、替换脱敏、假名化脱敏五种规则类型。当前 `MaskRuleExecutor` 已实现真实脱敏逻辑（`MaskFunctions.apply()`），需补充：

1. 移除 `RuleExecutionService` 中 SIMULATED 短路返回逻辑（若存在）。
2. 增加 Mock 模式开关 `rule-engine.execution.mock-enabled`（默认 false），仅在降级场景启用。
3. 增加脱敏规则执行审计日志，记录规则 ID、输入长度、脱敏策略、执行耗时，不记录原始值与脱敏值（避免审计日志泄露敏感数据）。

代码示例：rule-engine Mock 清零前后对比（Java）

```java
// 整改前（Mock 未清零）：RuleExecutionService 短路返回 SIMULATED
public RuleExecutionResult execute(Rule rule, Map<String, Object> context) {
    if (mockEnabled) {
        return RuleExecutionResult.builder()
                .ruleId(rule.getId())
                .status("SIMULATED")
                .message("MOCK_NOT_CLEARED")
                .build();
    }
    // ... 真实执行逻辑被屏蔽
}

// 整改后（Mock 清零）：真实执行脱敏规则，按规则类型分发到对应执行器
public RuleExecutionResult execute(Rule rule, Map<String, Object> context) {
    RuleExecutor executor = executorRegistry.get(rule.getType());
    if (executor == null) {
        throw new IllegalArgumentException("unsupported rule type: " + rule.getType());
    }
    RuleExecutionResult result = executor.execute(rule, context);
    // 审计日志：仅记录元数据，不记录敏感值
    auditLog.info("rule executed: ruleId={}, type={}, status={}, durationMs={}",
            rule.getId(), rule.getType(), result.getStatus(), result.getDurationMs());
    return result;
}
```

##### 3.1.3.2 L3.7 脱敏规则真实执行

脱敏规则经 GitOps 版本化配置（`deploy/gitops/desensitize-rules.yaml`），运行时由 rule-engine 引擎加载并执行，脱敏结果写入 ABAC 上下文。

  - id: mask-phone

  - id: hash-email

##### 3.1.3.3 行级权限联动

X1 ABAC 层在运行时根据 Token claim + 资源安全标记 + 脱敏规则做访问判定，敏感列无权访问时返回脱敏值或拒绝。

代码示例：X1 ABAC 行级权限联动（Java）

```java
public Object evaluateAccess(String token, String resource, String column, Object value) {
    // 1. 解析 Token claim 获取用户角色与脱敏豁免标记
    TokenClaims claims = jwtParser.parse(token);
    boolean desensitizeExempt = claims.hasScope("pii:read-plaintext");

    // 2. 查询资源安全标记
    SecurityLabel label = securityLabelRepository.get(resource, column);

    // 3. 敏感列且无豁免：执行脱敏
    if (label.isSensitive() && !desensitizeExempt) {
        DesensitizeRule rule = ruleRepository.get(label.getDesensitizeRuleId());
        RuleExecutionResult result = ruleEngine.execute(rule, Map.of("value", value));
        return result.getDetails().get("maskedValue");
    }

    // 4. 非敏感列或有豁免：返回明文
    return value;
}
```

##### 3.1.3.4 端到端测试

验证敏感数据（身份证号、手机号）展示时被正确脱敏，无权用户看到脱敏值，有权用户看到明文。

测试用例：

- TC-R01-01：无 `pii:read-plaintext` scope 的用户查询含身份证号字段，返回掩码值 `110101********1234`。
- TC-R01-02：有 `pii:read-plaintext` scope 的用户查询含身份证号字段，返回明文。
- TC-R01-03：手机号字段经 `mask:3,4` 脱敏，返回 `138****5678`。

代码示例：KMS 分级加解密（Java）

```java
public class KmsColumnCipher {
    private final KmsClient kmsClient;       // KMS API 客户端
    private final CryptoProvider crypto;     // encaps-layer 加密提供者

    public byte[] encrypt(String column, byte[] plaintext) {
        // 1. 从 KMS 获取数据密钥（DEK），由主密钥（KEK）解密
        DataKey dek = kmsClient.generateDataKey("pii-master-key");
        // 2. 用 DEK 加密列数据
        byte[] ciphertext = crypto.symmetricEncrypt(dek.getPlaintext(), plaintext);
        // 3. 返回加密后的数据密钥密文 + 列密文
        return encodeEnvelope(dek.getCiphertext(), ciphertext);
    }

    public byte[] decrypt(String column, byte[] envelope) {
        EnvelopeParts parts = decodeEnvelope(envelope);
        // 1. 从 KMS 解密数据密钥
        DataKey dek = kmsClient.decryptDataKey(parts.getDekCiphertext());
        // 2. 用 DEK 解密列数据
        return crypto.symmetricDecrypt(dek.getPlaintext(), parts.getCiphertext());
    }
}
```

代码示例：SSH 执行器实现（Go）

```go
// SshExecutor SSH 远程命令执行器，替换 localExecutor Mock
type SshExecutor struct {
    config   *ssh.ClientConfig
    port     int
    logger   *slog.Logger
}

func NewSshExecutor(username string, authMethod ssh.AuthMethod, port int, logger *slog.Logger) *SshExecutor {
    config := &ssh.ClientConfig{
        User:            username,
        Auth:            []ssh.AuthMethod{authMethod},
        HostKeyCallback: ssh.FixedHostKey(nil), // 生产环境应加载已知主机密钥
        Timeout:         30 * time.Second,
    }
    return &SshExecutor{config: config, port: port, logger: logger}
}

func (e *SshExecutor) Execute(ctx context.Context, host, command string) (string, string, int, error) {
    addr := fmt.Sprintf("%s:%d", host, e.port)
    client, err := ssh.Dial("tcp", addr, e.config)
    if err != nil {
        return "", "", -1, fmt.Errorf("SSH 连接失败: %w", err)
    }
    defer client.Close()

    session, err := client.NewSession()
    if err != nil {
        return "", "", -1, fmt.Errorf("创建 SSH session 失败: %w", err)
    }
    defer session.Close()

    var stdout, stderr bytes.Buffer
    session.Stdout = &stdout
    session.Stderr = &stderr

    err = session.Run(command)
    exitCode := 0
    if err != nil {
        if exitErr, ok := err.(*ssh.ExitError); ok {
            exitCode = exitErr.ExitStatus()
        } else {
            return stdout.String(), stderr.String(), -1, err
        }
    }
    return stdout.String(), stderr.String(), exitCode, nil
}

func (e *SshExecutor) CopyFile(ctx context.Context, host, localPath, remotePath string) error {
    // 使用 SCP 或 SFTP 拷贝文件
    return e.scpCopy(host, localPath, remotePath)
}
```

#### 3.6.3 落地实现

##### 3.6.3.1 SM2 证书登录 SPI

扩展 Keycloak SPI 支持 SM2 证书认证流。SPI 实现 `Authenticator` 接口，从请求中提取 SM2 证书，调用 R03 的 `GmCardProvider.validateSm2Certificate()` 验证证书，验证通过后创建用户会话。

代码示例：Keycloak SM2 证书登录 SPI（Java）

```java
public class Sm2CertificateAuthenticator implements Authenticator {
    private final GmCardProvider gmCard;  // R03 国密卡提供者

    @Override
    public void authenticate(AuthenticationFlowContext context) {
        // 1. 从请求中提取 SM2 证书（TLS 客户端证书或 HTTP Header）
        X509Certificate sm2Cert = extractSm2Certificate(context.getHttpRequest());
        if (sm2Cert == null) {
            context.failureChallenge(Errors.CERTIFICATE_NOT_FOUND,
                    Response.status(401).entity("SM2 证书缺失").build());
            return;
        }

        // 2. 调用国密卡验证 SM2 证书
        if (!gmCard.validateSm2Certificate(sm2Cert)) {
            context.failureChallenge(Errors.CERTIFICATE_INVALID,
                    Response.status(401).entity("SM2 证书验证失败").build());
            return;
        }

        // 3. 根据证书 subject 查找用户
        UserModel user = findUserByCertSubject(context.getRealm(), sm2Cert.getSubjectX500Principal());
        if (user == null) {
            context.failureChallenge(Errors.USER_NOT_FOUND,
                    Response.status(401).entity("证书关联用户不存在").build());
            return;
        }

        // 4. 设置用户会话，Token 签名切换为 SM2withSM3
        context.setUser(user);
        context.success();
    }
}
```

import httpx
from openapi_catalog.config.settings import Settings


class ApisixAdminClient:
    """APISIX Admin API 真实客户端，替换 Mock 下发."""

    def __init__(self, settings: Settings) -> None:
        self.base_url = settings.apisixAdminUrl.rstrip("/")
        self.admin_key = settings.apisixAdminKey
        self.timeout = settings.apisixAdminTimeout
        self._client = httpx.AsyncClient(
            base_url=self.base_url,
            headers={"X-API-KEY": self.admin_key},
            timeout=self.timeout,
        )

    async def deploy_route(self, route_id: str, payload: dict) -> dict:
        """真实下发路由到 APISIX Admin API.

        Args:
            route_id: 路由 ID.
            payload: APISIX Route 资源 payload.

        Returns:
            APISIX Admin API 响应.
        """
        resp = await self._client.put(f"/apisix/admin/routes/{route_id}", json=payload)
        resp.raise_for_status()
        return resp.json()

    async def undeploy_route(self, route_id: str) -> dict:
        """真实删除 APISIX 路由."""
        resp = await self._client.delete(f"/apisix/admin/routes/{route_id}")
        resp.raise_for_status()
        return resp.json()

    async def deploy_consumer(self, username: str, payload: dict) -> dict:
        """真实下发 Consumer 到 APISIX Admin API."""
        resp = await self._client.put(f"/apisix/admin/consumers/{username}", json=payload)
        resp.raise_for_status()
        return resp.json()

    async def add_ip_blacklist(self, ip: str, ttl_seconds: int = 1800) -> dict:
        """动态添加 IP 黑名单（ip-restriction 插件）."""

            "/apisix/admin/plugin_configs/ip-blacklist",

代码示例：Alertmanager webhook 联动 APISIX 动态封禁（Python）

```python
from fastapi import APIRouter, Request
from openapi_catalog.services.apisix_config import ApisixAdminClient

router = APIRouter()


@router.post("/webhook/apsix-ban")
async def apsix_ban_webhook(request: Request):
    """Alertmanager webhook receiver，联动 APISIX 动态封禁源 IP.

    Alertmanager 告警触发后调用此 webhook，从告警标签提取源 IP，
    调用 APISIX Admin API 添加 ip-restriction 黑名单规则。
    """
    payload = await request.json()
    apisix_admin: ApisixAdminClient = request.app.state.apisix_admin
    ban_ttl = request.app.state.settings.apisixBanTtlSeconds  # 默认 1800s

    results = []
    for alert in payload.get("alerts", []):
        # 从告警标签提取源 IP
        source_ip = alert.get("labels", {}).get("source_ip")
        if not source_ip:
            continue

        # 调用 APISIX Admin API 添加 IP 黑名单
        try:
            resp = await apisix_admin.add_ip_blacklist(source_ip, ttl_seconds=ban_ttl)
            results.append({
                "alert_id": alert.get("fingerprint"),
                "source_ip": source_ip,
                "ban_ttl": ban_ttl,
                "status": "banned",
                "apisix_response": resp,
            })
        except Exception as e:
            results.append({
                "alert_id": alert.get("fingerprint"),
                "source_ip": source_ip,
                "status": "failed",
                "error": str(e),
            })

    return {"results": results}
```

##### 3.11.3.2 镜像签名校验 Webhook

Webhook 服务接收 K8s AdmissionReview 请求，提取 Pod 中的镜像，调用 cosign 或国密签名验证工具校验镜像签名。

代码示例：镜像签名校验 Webhook（Java）

```java
@RestController
public class ImageSignatureAdmissionController {

    @PostMapping("/validate/image-signature")
    public AdmissionReview validate(@RequestBody AdmissionReview review) {
        Pod pod = extractPod(review.getRequest().getObject());
        List<String> images = extractImages(pod);

        for (String image : images) {
            // 1. 校验镜像仓库白名单
            if (!isAllowedRegistry(image)) {
                return reject(review, "镜像仓库不在白名单: " + image);
            }
            // 2. 校验镜像签名（cosign 或国密签名）
            if (!verifyImageSignature(image)) {
                return reject(review, "镜像签名验证失败: " + image);
            }
        }

        return allow(review);
    }

    private boolean verifyImageSignature(String image) {
        // 信创 Profile：国密签名验证（调用 R03 GmCardProvider）
        // 非信创 Profile：cosign 签名验证
        return imageSignatureVerifier.verify(image);
    }
}
```

```python
from datetime import datetime


class DqIncidentTicketCreator:
    """数据质量规则执行失败时自动创建工单，路由到值班人员."""

    def __init__(self, ticket_client, oncall_client):
        self.ticket_client = ticket_client    # 工单系统客户端
        self.oncall_client = oncall_client    # 值班系统客户端

    async def on_rule_failure(self, rule_result):
        """规则执行失败时创建工单.

        Args:
            rule_result: 规则执行结果，含规则 ID、违规表、违规行数、违规详情.
        """
        # 1. 查询当前值班人员
        oncall_user = await self.oncall_client.get_current_oncall("data-governance")

        # 2. 创建工单
        ticket = {
            "title": f"[数据质量漏洞] 规则 {rule_result.rule_id} 执行失败",
            "description": (
                f"规则 ID: {rule_result.rule_id}\n"
                f"违规表: {rule_result.table}\n"
                f"违规行数: {rule_result.violation_count}\n"
                f"违规详情: {rule_result.violation_details}\n"
                f"检测时间: {datetime.now().isoformat()}\n"
                f"优先级: {self._compute_priority(rule_result)}"
            ),
            "assignee": oncall_user,
            "labels": ["data-quality", "auto-created", rule_result.table],
            "due_date": self._compute_due_date(rule_result),
        }
        created = await self.ticket_client.create_ticket(ticket)

        # 3. 通知值班人员
        await self.oncall_client.notify(oncall_user, {
            "type": "dq-incident",
            "ticket_id": created["id"],
            "rule_id": rule_result.rule_id,
            "violation_count": rule_result.violation_count,
        })

        return created

    def _compute_priority(self, rule_result):
        """根据违规行数与表重要性计算工单优先级."""
        if rule_result.violation_count > 1000:
            return "P1"
        elif rule_result.violation_count > 100:
            return "P2"
        else:
            return "P3"

    def _compute_due_date(self, rule_result):
        """根据优先级计算修复截止时间."""
        priority = self._compute_priority(rule_result)
        if priority == "P1":
            return datetime.now() + timedelta(hours=4)
        elif priority == "P2":
            return datetime.now() + timedelta(hours=24)
        else:
            return datetime.now() + timedelta(days=3)
```
